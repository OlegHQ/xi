# Vim pattern requirements tracked by T005

Reference: the pinned Neovim 0.12.4 `runtime/doc/pattern.txt` and `runtime/doc/change.txt` files, whose hashes are recorded in `tests/oracle/manifest.json`. The upstream reference is [Neovim pattern help](https://neovim.io/doc/user/pattern/). This is a requirements inventory, not a claim that the spike or Xi currently implements them.

Status terms: **prototype** means the disposable T005 feasibility evaluator has fixture evidence; **required** means production work is still owned by the listed ticket; **boundary** means the underlying arbitrary Vimscript/plugin facility is outside parity and needs the documented Xi/provider boundary rather than an implicit claim of support.

| ID | Requirement | T005 status | Production owner and acceptance route |
|---|---|---|---|
| VP-01 | `'magic'`/`'nomagic'`, `\m`, `\M`, `\v`, `\V`, and the exact special-character table for each mode, including mode switches inside a pattern | prototype: common ASCII cases only (`PATT-MAGIC-01`, `PATT-MAGIC-SWITCH-01`) | T096: exact regular parser tables and source-span diagnostics |
| VP-02 | Case controls `\c`, `\C`, `'ignorecase'`, `'smartcase'`, last-pattern state, and interactions with search/substitute commands | prototype: inline `\c`/`\C` and an explicit initial option only; no option-derived smartcase | T096: pattern-local case semantics; T027: search/substitute options and last-pattern state |
| VP-03 | Concatenation, alternation, branch intersection `\&`, grouping, non-capturing `\%(`, optional atom sequences `\%[]`, and syntax-only `\z(` groups | prototype: concatenation, alternation, captures and `\%(`; other forms unsupported | T096: regular concat/alternate/group semantics; T097: branch intersection and optional-sequence extensions; `\z(` remains an explicit syntax-only boundary |
| VP-04 | Greedy and shortest-first `*`, `\+`, `\=`, `\?`, and all `{n,m}` forms, including exact, open, bounded, and shortest-first repetitions | prototype: common greedy/lazy repeats and bounds; full Vim precedence and corner cases remain unproven | T096: NFA quantifier precedence, full regular forms, diagnostics and adversarial budgets |
| VP-05 | Vim atoms, escaped literals, anchors, character classes/ranges, POSIX classes and the full built-in class family (`\i`, `\k`, `\f`, `\p`, `\x`, `\o`, `\h`, `\a`, `\l`, `\u`, and complements) | prototype: literals, `.`, `[]`, `\d`, `\w`, `\s`, and their basic complements; word classes are ASCII plus underscore | T096: regular atoms/classes and explicit unsupported errors; T026: snapshot-bound option-dependent `iskeyword`, `isident`, `isfname`, `isprint` and Unicode option behavior; T027: command-level option propagation/search integration |
| VP-06 | Newline-inclusive atoms/classes (`\_.`, `\_s`, etc.), explicit `\n`, `\_^`, `\_$`, file EOL behavior, and matches crossing document lines | prototype: `\_.`, `\_s`/`\_S`/`\_w`/`\_W`/`\_d`/`\_D`, `\n`, `\_^`, `\_$`; only the tested `\_s` multiline form is oracle-covered | T096: regular newline atoms/classes and evaluator boundaries; T027: command range/count/undo integration |
| VP-07 | Captures 1–9, capture participation/clearing under alternation and repetition, backreferences, and case-sensitive/insensitive reuse | prototype: simple participating captures and `\1` (`PATT-BACKREF-01`) | T096: regular capture priority/participation; T097: bounded backreference fallback and capture reuse |
| VP-08 | Positive/negative lookahead, positive/negative lookbehind, Vim's variable-width and line-bounded lookbehind rules, numeric lookbehind limits, and atomic `\@>` | prototype: four assertions; lookbehind is limited to statically measured width ≤1024 UTF-16 units | T097: bounded lookaround/atomic extensions, with typed source errors and explicit work limits |
| VP-09 | Zero-width progression, anchors, word boundaries, `\zs`/`\ze` reported spans, nested/repeated markers, and consumption versus reported-range distinctions | prototype: simple `\zs`/`\ze`, line starts, word edges, and bounded global advancement (`PATT-ZS-01`, `PATT-ZE-01`, `PATT-ZERO-01`, `PATT-EMPTY-01`, `PATT-ZERO-LOOP-01`) | T096: regular evaluator spans, anchors, and zero-width progression; T098: coordinate-boundary completion; T027: command advancement/range/termination |
| VP-10 | Positional atoms `\%^`, `\%$`, `\%#`, `\%V`, marks (`\%'m`, `\%<'m`, `\%>'m`), line/byte-column/virtual-column comparisons, cursor-relative forms and document-version validity | Xi evaluator: T098 pinned matrix covers file/cursor/visual/mark/line/byte/virtual forms, including linewise/blockwise selections and stale-version source errors; command integration remains T027 | T098: snapshot-bound cursor, selection, marks, tabstop, byte/virtual-column and Unicode coordinates |
| VP-11 | Vim's engine selectors `\%#=0/1/2`, old-engine/NFA observable differences, Unicode combining behavior (`\Z`, bare combining literals, and default literal/dot/class spans over attached marks), and code-point atoms `\%d`, `\%x`, `\%o`, `\%u`, `\%U`, `\%C`, including NUL in real buffer contents | Verified against pinned Neovim 0.12.4 by T097/T100 production fixtures; runtime Neovim remains prohibited | T097: selector, directive, code-point parser and bounded-path behavior; T100: bare marks, default atom cluster spans/captures, NUL and supplementary-codepoint real-buffer oracle; no engine selector may start or link runtime Neovim |
| VP-12 | Replacement expansion: `&`, `\0`–`\9`, literal escapes, newline/NUL rules, case conversion (`\u`, `\l`, `\U`, `\L`, `\E`), and previous replacement `~`/`\~` | prototype: `&`, `\0`–`\9`, `\&`, `\\`, and `\r` newline for the tested cases | T027 replacement parser, captures, delimiters, flags and undo transaction |
| VP-13 | Expression replacement `\=`, substitute expression callbacks, and arbitrary Vimscript evaluation | not implemented | `docs/plan/01-architecture.md` extension boundary: no arbitrary Vimscript parity; any Xi equivalent is an explicit typed provider/command, never evaluation of user Vimscript |
| VP-14 | Search command semantics: `/`, `?`, `n`, `N`, `*`, `#`, `g*`, `g#`, offsets, direction, wrap/no-wrap, empty-pattern reuse, preview/cancel, and committed repeat state | not implemented by this parser spike | T027 owns buffer search state and substitution command integration |
| VP-15 | Resource control: regular-subset NFA execution, bounded fallback for non-regular features, deterministic work/output budgets, cancellation and resumable/cooperatively sliced evaluation over versioned snapshots | prototype: bounded AST backtracking, output limit, cancellation predicate every configured number of AST steps (`PATT-CATASTROPHIC-01`, `PATT-CANCEL-01`) | T096: regular NFA budgets/resumability/cancellation; T097: bounded non-regular fallback; T098: cross-path snapshot/resource completion; T027: preserve command view/edit state |
| VP-16 | Coordinate contract across UTF-8 oracle byte columns, document offsets, pattern source spans, line breaks and grapheme/virtual cells | Xi evaluator: T098 verifies UTF-8 byte ↔ UTF-16 conversion at scalar boundaries, source-aware stale/context errors, newline line coordinates, composing spans, tabs and wide cells; command integration remains T027 | T098: explicit document/source/oracle coordinate conversion and astral, combining, tab, wide-cell fixtures |

T005's supported subset is feasibility evidence only. Production inventory rows become verified only after their owning ticket passes the pinned-oracle and Xi-specific acceptance checks listed here; remaining rows keep their explicit partial/unimplemented status. The prototype deliberately raises typed errors for syntax it cannot parse; this does not satisfy parity for that syntax.
