## Observable result

`IncrementalSyntaxHighlighter` accepts immutable `{documentId, documentVersion, requestId, generation, text, delta}` requests and returns synchronously after bounded enqueue. Parsing is scheduled on a bounded event-loop worker queue, so grammar initialization and parsing never occur on the typing call stack. A versioned line cache reparses the changed line and propagates lexical state until an unchanged suffix can be reused; cached spans are relative to their line and are rebased when edits shift offsets. The result is integrated only when its request sequence is still current, so stale work cannot repaint newer text.

The pinned `web-tree-sitter` runtime is loaded lazily through `initializeTreeSitterRuntime`; explicit grammar loading reports a typed missing-grammar failure. The built-in tokenizer supplies immediate highlighting while an optional grammar is unavailable. Very large documents and giant lines use a plain-text result with an explicit fallback reason. A parser input failure is caught and also returns plain text. `packages/ui/editor` clips immutable syntax spans to visible UTF-16 ranges with a hard span limit and reports truncation; it does not own text or parse input.

## Performance and visual evidence

The benchmark uses a deterministic 2,000-line JavaScript-like corpus and inserts a line near the beginning 200 times. The last edit demonstrates suffix reuse (`2` reparsed lines, `2,198` reused lines) and a maximum queued depth of `1`; this is an exploratory local measurement, not a release typing budget. The `T053-STALL-*` fixture uses 100,000 lines and confirms input delivery between resumable full-resync slices. Span projection is tested as cell-independent UTF-16 clipping. Terminal screenshot review is not applicable to this service ticket; T034 owns the workbench visual gate.

## Failure cases and recovery

`T053-GRAMMAR-MISSING-01` loads a nonexistent WASM grammar and receives `{kind: 'grammar-missing'}` without affecting the built-in parser. `T053-PARSER-CRASH-01` supplies an unpaired UTF-16 surrogate; the parser guard contains the failure and publishes a plain-text result. `T053-GIANT-LINE-01` and `T053-LARGE-FILE-01` verify bounded plain-text fallback. The stale fixture queues two versioned requests before the worker runs and confirms only the latest result is retained. Disposal drops queued work and listeners.

## Limitations and next action

No grammar WASM is bundled in this repository yet; grammar loading is explicit and lazy, while the deterministic tokenizer provides immediate fallback highlighting. T112 still owns service-wide worker isolation and aggregate loaded-system qualification; this ticket proves cooperative syntax slices at the service boundary. T054 owns semantic-token layering over these syntax spans; T062/T087 own broader loaded-system performance qualification.
