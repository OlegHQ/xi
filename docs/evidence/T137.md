## Observable result

`packages/ui/src/terminal.ts` creates one native `WorkbenchRenderable` for the editor viewport and mounts one Solid root through `packages/ui/src/solid/root.tsx`. Shell, tabs, sidebar projection and status are composed by `WorkbenchApp`, `ChromeSurface` and `StatusSurface`. The native renderable retains only incremental editor-cell painting, viewport geometry and semantic pointer hit testing.

The old shell/sidebar/status painting and per-surface property synchronization were removed. Theme updates reach the Solid surfaces through the shared `SolidThemeBridge`; editor theme state remains owned by the viewport.
