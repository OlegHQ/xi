## Observable result

The Vim selection owner now exposes all required `selection.*` operations, including bounded immutable history undo. Literal selection creation uses the owned pattern engine on a versioned snapshot; regex selection is restricted to the selected regions; zero-width results and EOF use validated semantic endpoints. Add-above/below uses each member’s retained column and makes the newly added frontier primary. Selection changes publish one canonical set, preserve the prior set on cancellation, member-limit overflow, and empty filtering, and leave document text/search state untouched.

The standalone launcher accepts `:Xi selection.…` from Normal and Visual modes. A real PTY flow selects both `one` occurrences, collapses to two Normal cursors, inserts one shared `X`, writes the file, and exits without mouse input or terminal modifier chords.
