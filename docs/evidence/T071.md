## Observable result

The workbench resolves file and tag locations through asynchronous platform ports, opens or focuses buffers, places the cursor at the requested zero-based line and UTF-16 column, and keeps editor-window focus separate from panel focus. Ordinary key handling remains synchronous until a host operation is explicitly requested.

Unsupported providers and window actions produce explicit messages. No shell text, runtime Neovim process, or direct filesystem call was added to the Vim engine.

## Performance and visual evidence

No new T071 performance budget or visual surface was introduced. `gf/gF`, tag, and include host effects return from the synchronous Vim key handler before filesystem reads; asynchronous file/tag resolution runs behind the host boundary. The dedicated startup, CPU, RSS, retention, and interaction performance gates remain unproven in their own tickets and are not counted as T071 evidence.

## Failure cases and recovery

- Missing file: explicit `missing` host failure and `xi: file target not found` message; covered by `T071-MISSING-01` and the production resolver.
- Missing or ambiguous tag: explicit missing/ambiguous controller outcomes; covered by `T071-TAG-FAIL-01` and `T071-MISSING-01`.
- Filename with line number: `gF` strips the trailing `:N`, converts the one-based file line to the zero-based host location, and was compared with the pinned oracle fixture and production PTY.
- Split minimum size: workbench `split-too-small` remains typed and the existing T038 resize fixture passes; host window split errors are reported without stealing focus.
- Stale tag requests: `HostNavigationController` generation barriers return `stale` and disposal clears retained jump history.

## Limitations and next action

The host boundary is complete for the ticket’s acceptance scope. Xi currently reports explicit unavailable outcomes for provider-dependent `gD/gd`, `K`, `g<`, include-list forms, and advanced `Ctrl-W` exchange/rotation/move/resize actions until their providers or geometry mutation contracts are implemented. These are retained as visible boundaries rather than guessed behavior.
