## Observable result

`resolveVimWordMotion` is implemented in [`packages/vim/motions/word.ts`](../../packages/vim/motions/word.ts) and re-exported from [`packages/vim/src/index.ts`](../../packages/vim/src/index.ts). It resolves `w`, `W`, `b`, `B`, `e`, `E`, `ge`, and `gE` against a versioned document snapshot without changing document text or version. It uses the current `iskeyword` value on each call, observes grapheme boundaries, crosses line separators and empty lines, and returns the updated cursor and desired display column.

The ticket fixture catalog has 12 cases and the captured trace has 39 snapshots. The probes show the pinned default `@` behavior for the tested Unicode values: Greek letters are keyword characters; emoji form a distinct keyword class; supplementary numerals group with punctuation. `iskeyword` with `-` added changes `w` on `foo-bar baz` from the hyphen (UTF-16 offset 3) to `baz` (offset 8). The trace harness checks that fixture text and every initially nonempty register remain unchanged by motion-only steps.

## Performance and visual evidence

No latency target or rendered surface is defined by T017. The ordinary adjacent-word path was checked for source reads, not treated as a broad timing pass. The deterministic regression builds a 1,014,011 UTF-16-unit document with `alpha beta` on line 1, 2,000 intervening short lines, and a distant 1 MiB line. Resolving `w` from `alpha` reaches `beta`, asks for line-start indexes `[0,1]` only, and slices 21 UTF-16 units in total. This demonstrates no whole-document scan for that ordinary adjacent-word case. Word motions that cross longer spans still read the traversed text as needed.

## Failure cases and recovery

`T017-ORACLE-PUNCTUATION-ONLY-01` covers punctuation beside an empty line; `T017-ORACLE-EMPTY-LINES-01` covers consecutive and trailing empty lines; `T017-ORACLE-UNICODE-CLASSES-01` covers Latin-1, Greek, a combining grapheme, and emoji. `T017-ORACLE-UNICODE-AT-LETTER-01`, `T017-ORACLE-UNICODE-AT-NUMBER-01`, `T017-ORACLE-UNICODE-AT-EMOJI-01`, and `T017-ORACLE-UNICODE-AT-EMOJI-LETTER-01` distinguish the tested pinned Unicode classes. `T017-ORACLE-ISKEYWORD-DEFAULT-01` and `T017-ORACLE-ISKEYWORD-CUSTOM-01` pin the option change. The resolver also rejects stale versions, zero/unsafe counts, invalid tab size, and a cursor inside a combining grapheme without mutating the document.

## Limitations and next action

- The trace is a fixture corpus, not a full Unicode code-point or full Neovim compatibility inventory. The shared inventory remains owned by T061.
- Cross-line motions necessarily inspect the lines crossed; the bounded-read check establishes only the ordinary adjacent-word case required by this ticket.
- The public resolver is tested directly. Parser-to-engine-to-UI keystroke integration and end-to-end launch readiness are separate validation work and are not claimed here.
