## Observable result

The spike is a custom recursive-descent Vim-dialect parser with source-spanned IR and a bounded AST backtracking evaluator. No JavaScript `RegExp` translation or replacement is used, and no Neovim runtime dependency exists. The parser/evaluator supports a small demonstrated subset across magic switches, captures/backreferences, four lookaround forms, newline atoms, word/line/file anchors, cursor/line position atoms, `\zs`/`\ze`, substitution replacement basics and zero-width progress. A recognized unsupported engine selector is rejected as a source-located `unsupported-construct` error. The complete partial/unimplemented inventory routes parser/evaluator work to T026 and search/substitution command work to T027.

All 16 semantic fixture outputs matched Neovim 0.12.4. `PATT-POSITION-CURSOR-UNICODE-01` also verifies conversion of a UTF-8 byte cursor column to the prototype's UTF-16 offset at a character boundary. This is fixture-result parity for the selected examples, not full Vim regex parity or direct oracle comparison of private spans/captures.

## Performance and visual evidence

The spike measured bounded cancellation checks, not editor input-to-paint latency. The 31 cancellation samples used the same nested-repeat fixture and cancelled after 512 AST steps; latest p50 was 211.792 µs, p95 414.334 µs and maximum 2,269.752 µs. The 50,000-step adversarial budget stopped after the 50,001st attempted step in 25,570.070 µs. These measurements were taken on a virtualized host without an exposed CPU model and are not release thresholds. No UI or terminal adapter is involved, so screenshots and visual review do not apply.

## Failure cases and recovery

- `PATT-CATASTROPHIC-01`: deterministic work-budget exhaustion returns `step-budget-exceeded` instead of a successful no-match; the reported count is one step over the configured budget because the evaluator checks after incrementing.
- `PATT-ZERO-LOOP-01` and `PATT-EMPTY-01`: zero-width advancement terminates across multiple lines and matches the pinned substitute output.
- `PATT-UNSUPPORTED-ENGINE-01`: unsupported engine selection fails at parse time with a typed source span.
- `PATT-CANCEL-01`: cancellation returns `cancelled` at the configured polling boundary; it does not claim event-loop yielding or product-state rollback.

## Limitations and next action

The implementation is disposable feasibility code. It uses synchronous backtracking even for regular patterns, builds a full line-start table for each full input string, does not yield the event loop, and has no direct `DocumentSnapshot` or version-aware API. Lookbehind is limited to statically measured width ≤1,024 UTF-16 units. Unicode classes/case folding, option-dependent classes, complete magic/quantifier behavior, branch intersection, atomic groups, many positional atoms, full replacement syntax, command-level search options/state, and direct span/capture/error parity remain incomplete. Each surfaced item is routed in `spikes/vim-pattern/requirements.md`; the T005 result remains partial as a product feature. T026 must close VP-01–VP-11 and VP-15–VP-16 with the production NFA/backtracking, source-error, versioned snapshot and cooperative cancellation contracts; T027 owns VP-12–VP-14. T061 still audits the full command/help inventory.
