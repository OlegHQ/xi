## Observable result

`LanguageServerNavigationProvider` sends the native LSP definition, hover and
document-symbol requests and validates Location, LocationLink, SymbolInformation,
DocumentSymbol and hover markup responses. The provider preserves UTF-16
coordinates, rejects malformed data and strips terminal escape sequences from
hover text before exposing it to the UI.

`LanguageNavigationController` owns request generations, publishes immutable
read models, suppresses late Outline/hover/definition results and retains the
origin request for focus return. An absent server is rendered as an explicit
unavailable Outline/hover state; no symbols are synthesized from source text.
The production launcher starts the configured TypeScript session asynchronously
for `.ts`/`.tsx` files and exposes Outline with `Space v o` and hover with
`Space k`. Both overlays close with Esc and return input to the editor.

## Performance and visual evidence

Language startup and requests are asynchronous and do not delay the initial
editor frame. Outline and hover rows are bounded by the renderable dimensions;
hover text is capped at 64 KiB at the service boundary. No numeric latency,
allocation or reference-host qualification is claimed; those gates remain in
T106/T109–T118/T115 and the downstream UX qualification.

## Failure cases and recovery

- `T050-OUTLINE-02`: an older symbol response cannot replace a newer generation.
- `T050-EXTERNAL-URI-01`: definitions outside `file://` are rejected before host navigation.
- Malformed ranges, symbols and hover markup produce typed unavailable results.
- Esc increments the navigation generation, closes the overlay and invalidates a
  response that arrives after dismissal.
