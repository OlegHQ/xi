## Observable result

The Xi-owned pattern evaluator handles branch intersection, optional atom sequences, bounded backreferences, positive and negative lookaround, variable and line-bounded lookbehind, numeric lookbehind limits, atomic groups, engine selectors and Unicode code-point atoms. Bare combining literals, composed and precomposed literals, dot, classes, `\Z`, and `\%C` now use the pinned Vim behavior over composed clusters. Selectors 0/2 use the regular NFA where the pattern is regular; selector 1 and patterns needing extensions use the bounded evaluator. NUL and supplementary code points are verified through a real file-loaded Neovim buffer. Neovim is only a development oracle and is not a runtime dependency.

The retained T100 differential matrix includes 50 minimized probes across selectors 0/1/2, with byte spans and captures for composed, precomposed, multiple-mark and pattern-leading-mark cases. It records the old engine's observed span/capture differences: a plain `[a]` reports only the base, dot reports the complete cluster, composed literals require the exact ordered suffix, and a captured bare combining literal has an empty capture under selector 1. The raw-buffer fixture searches a nine-byte file containing NUL and an emoji without passing NUL through a Lua string API.

## Performance and visual evidence

Visual evidence is not applicable to the pure pattern evaluator. The T097 benchmark measured 64-unit ambiguous-backreference and 512-unit variable-lookbehind failures; both exercised the exact deterministic 20,000-step work limit. The T100 stress benchmark completed a 20,001-UTF-16-unit composed cluster in 20,007 steps and stopped an adversarial 5,001-unit cluster at step 1,025 for a 1,024-step budget. Timings in the retained artifacts are exploratory, run on Linux aarch64 with Bun 1.3.13; they do not claim an interactive latency threshold or event-loop scheduling behavior.

## Failure cases and recovery

The tests verify deterministic source-spanned budget failures, output-limit errors, resumable fallback and NFA sessions, cancellation during a composing-cluster scan, stale snapshot-version failures, exact Unicode source ranges, detached versus attached marks, precomposed mismatch, multiple marks and NUL in a real buffer. Repeated adversarial runs report identical step counts and source spans. Runtime Neovim remains prohibited by architecture checks.
