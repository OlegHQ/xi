## Observable result

`LanguageDocumentSync` owns one bounded, serialized notification stream for a transport. A committed snapshot is admitted only at the exact next Xi document version. `didOpen` is always queued before `didChange`; incremental changes are encoded as one valid range from the server's last sent text to the newest committed target, while full-sync servers receive a snapshot. Pending commits collapse to the newest target without changing the server baseline, and `didClose` drains admitted changes before closing. A replacement language transport can replay the latest committed snapshot through `openDocument` without replaying stale ranges.

The client advertises UTF-8, UTF-16 and UTF-32 position encodings. The server's selected encoding is negotiated with UTF-16 fallback. Outbound ranges and the exported position conversion helpers preserve astral scalar boundaries, combining text and normalized LF lines. Closed documents and non-monotonic versions are rejected before protocol I/O. The session now creates the sync owner from initialize capabilities, routes open/change/close through it, and retains the latest committed snapshot for crash replay.

## Performance and visual evidence

No visual or keystroke budget applies to this service-owned protocol queue. The test uses deterministic immediate fake transport notifications; queue coalescing retains one pending target per document and does not scan or mutate the document on the input path. Full-sync documents are bounded at 8 MiB (UTF-16 units) by default and return a typed `document-too-large` failure above that limit.

## Failure cases and recovery

- `LSP-T048-CLOSE-DURING-CHANGE-01`: a pending committed edit is delivered before `didClose`; no post-close change is admitted, and the sequence is verified as `didOpen → didChange → didClose`.
- `LSP-T048-STALE-GENERATION-01`: a version jump is rejected as `stale-version` before a notification is queued; post-close snapshots are rejected as `closed-document`.
- `LSP-T048-SERVER-RESTART-01`: the replacement sync owner opens the latest committed version once and emits no stale `didChange`; T047 additionally verifies lifecycle crash/retry replay.
- `LSP-T048-ASTRAL-RANGE-01`: UTF-16 columns count surrogate code units, UTF-32 columns count scalar values, and ranges never split the astral scalar.
- `LSP-T048-FULL-LIMIT-01`: full-sync-only targets above the documented limit return `document-too-large` and retain the previous sent baseline.
