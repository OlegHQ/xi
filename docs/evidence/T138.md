## Observable result

`packages/ui/src/solid/panel.tsx` owns one bounded `RowsSurface<T>` implementation for Explorer, search, Git, Git diff, problems, task output, outline, hierarchy and their row-based views. It owns subscriptions, visibility, bounded formatting, selection-follow scrolling, scrollbar rendering, wheel input and pointer hit-map forwarding. Surface-specific formatters and semantic controllers remain in their existing owners.

The former panel `Renderable` classes and `installPanelPointerHandler` path were removed. Offscreen results stay in controller read models; Solid receives only bounded visible content through the formatter contract.
