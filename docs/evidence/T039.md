## Observable result

`FilePathIndex` keeps root identity in every file entry and performs bounded
fuzzy matching with explicit hidden, ignored and not-ready states. The platform
filesystem adapter enumerates workspace files asynchronously in 512-entry batches;
the composition root never imports OS filesystem modules or scans during a key
path. `BoundedPickerModel` publishes immutable loading/result generations and
notifies the OpenTUI read-only picker surface without owning text.

The launcher activates `createNavigationContributionModule` through public
entrypoints, supports `Space f`/`Space b`/`Space ;`/`Space t`/`Space c`, and routes
picker input separately from the Vim session. File selection opens a preview
buffer; Escape explicitly discards that preview and restores the original active
view. Buffer selection focuses an existing view, while command/theme/config
entries remain bounded picker actions.

## Performance and visual evidence

The 100,000-path benchmark uses a deterministic mixed path corpus and bounded
warm queries. The production PTY checks the actual OpenTUI overlay and preview
journey. The picker renderer preserves selected identity, loading/error text and
visible truncation at narrow sizes; the isolated fixture captures 72x8 and 32x4
frames. Workspace enumeration is background work and does not block the editor
input queue. No release performance certification is inferred from this ticket;
the full T106/T115 matrix remains separate.

## Failure cases and recovery

- `T039-FAIL-STALE-01/02`: superseded provider results return `stale` and cannot replace the latest model.
- `T039-CANCEL-01/02`: external cancellation returns `cancelled` and leaves the model coherent.
- `T039-FAIL-NOT-READY-01`: a warming index is rendered as an explicit not-ready state; the production query retries after background readiness without blocking keys.
- `T039-FAIL-HUGE-PATH-01/02`: Unicode-safe truncation preserves the basename and never splits a surrogate pair.
- `T039-DUP-01` through `T039-DUP-04`: duplicate relative names retain distinct root-qualified IDs.
- `T039-PTY-PREVIEW-01`: the production preview marker is followed by `XI_PICKER_CANCELLED` with the original active view restored.
- `T039-UI-05`: renderer disposal destroys the picker and releases its subscription.
