## Observable result

`packages/selections` now constructs immutable, nonempty, versioned selection sets with stable IDs, explicit primary identity, monotonically advancing selection generation, creation ordinals and deterministic document-order iteration. Discriminated endpoint types keep Normal semantic characters/empty lines/EOF, Insert gaps, Visual character inclusivity, Visual line anchors and Visual block display-cell positions distinct. UTF-16 offsets and logical UTF-16 columns remain separate from display-cell columns and virtual-cell counts.

Canonicalization returns a complete old-to-new ID map. It retains the primary member when a component merges, otherwise the oldest member, and preserves the retained member's direction. Exact duplicate carets with matching desired logical/display columns collapse; carets at the same location with different preferred columns remain distinct because later vertical motion can differ. Compatible character regions merge only on actual overlap, so adjacent regions and the exclusive right edge remain distinct. Visual block unions merge only when their display-cell rectangle adds no cells and their virtual corner geometry is compatible; disjoint, diagonal and incompatible virtual shapes remain separate.

`mapSelectionSet` collects every semantic endpoint, sorts and maps the anchors through one `DocumentChangeMap.mapSortedAnchors` batch, then re-anchors them to the destination snapshot and canonicalizes collisions. It preserves endpoint affinity, selection kind, direction, semantic positions and block metadata. If a document deletion erases a character endpoint, the mapped endpoint is normalized to a valid destination character, empty-line or EOF representation before the set is published. Selection-only updates preserve document version and advance only selection generation; the selection package stores no document text or history.

The source manifest contains `packages/selections/src/index.ts` and `tests/selections/t075.test.ts`. No `packages/primitives` changes were needed.

Not applicable to a UI or measured-latency gate. No numeric performance claim is made by T075, and no visual output changed.

## Failure cases and recovery

- When an overlapping component contains the primary, canonicalization retains its identity and direction, remaps the other ID to it, and updates `primaryId` consistently (`T075-MC02-OVERLAP-PRIMARY-01`).
- Same-location carets with different desired logical/display columns remain separate; matching desired columns permit exact duplicate collapse (`T075-MC02-DESIRED-COLUMNS`).
- A backward Visual character selection mapped through an interior deletion retains its direction and maps both endpoints to valid destination semantic positions (`T075-MC04-BACKWARD-DELETE-01`).
- A block union that is diagonal, disjoint or has incompatible virtual extents remains as separate members rather than selecting extra cells (`T075-MC02-BLOCK-DISJOINT-01`, `T075-MC02-BLOCK-VIRTUAL-INCOMPATIBLE-01`, `T075-MC02-BLOCK-INCOMPATIBLE-RECTANGLES-01`).
- Invalid empty sets, missing primary IDs, duplicate IDs, mixed selection kinds, surrogate-splitting offsets, nonempty lines represented as empty-line endpoints, invalid generations/ordinals and invalid EOF affinity return typed failures without publishing a set (`T075-MC02-CONSTRUCTOR-*`, `T075-MC04-CONSTRUCTOR-SURROGATE-01`).
- Selection-only updates leave document version, revision identity, saved revision, dirty state and document change notifications unchanged (`T075-MC02-UPDATE-DIRTY-01`).
