## Observable result

`GitMutationCoordinator` exposes separate stage, unstage, discard and commit operations through an injected argv executor. It serializes mutations, checks the status generation, blocks empty commit messages, and passes commit text through stdin (`-F -`). No operation performs push/network work implicitly.

## Performance and visual evidence

Mutation calls are explicit background operations; no Git process is launched from a render or ordinary keystroke callback. No standalone visual surface is introduced.

## Failure cases and recovery

Generation changes reject mutations before the executor. Executor failures remain typed and do not claim index changes. Disposal prevents new operations.
