## Observable result

`packages/vim/motions/viewport.ts` resolves screen/display-line motions and viewport intents from immutable, versioned `DocumentSnapshot` and `VisibleFrame` values. It preserves desired display/screen columns, validates stale or malformed context, handles fold rows and wrapped/wide graphemes, and returns immutable cursor/anchor outcomes without mutating the document. Ordinary `j/k/l` movement can be passed through `ensureVimCursorVisible` to apply scrolloff and sidescrolloff.

The PTY oracle helper now restores a deterministic initial topline before sending fixture input, supports explicit CTRL-E/Y/F/B tokens, and exposes `winsaveview()` state. This removes the startup offscreen-cursor artifact that made page commands incomparable to the baseline frame.

## Failure cases and recovery

- `T031-ORACLE-FOLD-DESTINATION-01` folds lines 3–6 and verifies counted `j` skips the folded body to line 7 while retaining valid screen positioning.
- `T031-ORACLE-WIDE-WRAP-01` compares a CJK-wide grapheme across wrapped display rows; `T031-ORACLE-TINY-VIEWPORT-01` covers a three-row window.
- `T031-ORACLE-HORIZONTAL-SCROLL-01` checks repeated `l` with `sidescrolloff=2`; `T031-ORACLE-SCROLLOFF-01` checks a counted `j` against the scrolloff band.
- Page scrolling was initially mismatched because the PTY command could run before the cursor view was reconciled (CTRL-F reported line 7 from an offscreen startup cursor). The PTY helper now sets a deterministic `winsaveview` topline before the fixture command; CTRL-F/B and CTRL-Y then match the pinned oracle.
- Resize checks project the same immutable semantic anchor at two geometries and query each frame before the per-view cache replaces the prior frame.
