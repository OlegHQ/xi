## Observable result

The language service sends native LSP completion and signature-help requests,
validates bounded responses, preserves completion resolve data, and suppresses
late results by document and selection generation. The launcher starts these
requests asynchronously for TypeScript files. Completion is opened with
Ctrl-Space in Insert mode; Ctrl-N/P selects, Ctrl-D/U scrolls documentation,
Tab accepts a selected item, Enter accepts only an explicitly selected item or
inserts a newline, and Esc cancels. Incomplete lists retrigger after typed
input. Commit characters apply the selected completion before forwarding the
typed character.

Accepted edits are converted from LSP UTF-16 line/column coordinates, checked
against the exact current snapshot, committed as one `lsp` undo transaction,
and mapped through all open workbench views and owned Vim sessions. Signature
help is exposed through a bounded OpenTUI overlay and can be explicitly
requested with Ctrl-Shift-S in Insert mode.

## Performance and visual evidence

Completion requests and signature help remain asynchronous; ordinary typing is
forwarded while a request is pending. Completion rendering is bounded to the
popup dimensions, documentation is capped at 64 KiB at the service boundary,
and accepted edits use one document transaction. Numeric keystroke latency,
allocation and reference-host qualification remain unproven under T106 and
T109–T118/T115. The UI surface matrix covers renderable construction and state
transitions; no screenshot review is claimed here.

## Failure cases and recovery

- `T051-OVERLAP-01`: overlapping additional edits fail before document mutation.
- `T051-LATE-01`: a resolve result after cancellation cannot republish.
- `T051-STALE-01`: a result for an old document version cannot publish or apply.
- Commit characters are applied only for the currently selected item and the
  character is forwarded after the transaction; a stale or unselected item is
  dismissed and typed normally.
- Invalid LSP positions, ranges and signature payloads produce typed service
  failures and do not mutate the document.
