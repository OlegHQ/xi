## Observable result

The Xi-owned pattern evaluator accepts version-bound cursor, mark, characterwise/linewise/blockwise visual-area, tabstop and display-width context. It evaluates `\%^`, `\%$`, `\%#`, `\%V`, mark equality/ordering, exact and relational line/byte/virtual columns, and cursor-relative line/byte/virtual columns. Numeric `\%Nv` compares the leading virtual cell of a character; cursor-relative `\%.v` uses the cursor cell within a wide glyph or tab, matching the pinned Neovim behavior.

Document offsets and captures remain UTF-16 boundaries. Oracle byte columns are converted only at UTF-8 scalar boundaries; line and byte-column comparisons are one-based Vim coordinates, while visual block cells are zero-based inclusive coordinates. Tabs expand using the captured tabstop, and other grapheme widths use the captured layout-compatible policy. Stale versions, invalid snapshot offsets and missing visual/mark context fail with typed, source-aware errors. Position-index work is budgeted and yielded through resumable NFA and bounded-fallback sessions. The evaluator does not own or mutate command cursor, document or repeat state.

## Performance and visual evidence

Visual evidence is not applicable to this pure evaluator. The benchmark used Linux aarch64 and Bun 1.3.13 with a 2,052-UTF-16-unit document, 3 warmups and 30 measured fresh sessions. The regular NFA positional workload measured p50 3,153.747 µs, p95 6,928.911 µs, p99/max 6,959.078 µs; the bounded backreference workload measured p50 3,455.455 µs, p95 5,448.704 µs, p99/max 5,622.495 µs. These exploratory timings have no target latency threshold and include no editor dispatch, terminal input or paint. The retained JSON records engine, deterministic work counts, exact failure spans and before/after state checks.

## Failure cases and recovery

Pinned cases reject byte columns inside a multibyte scalar, stale snapshot context and missing visual/mark context with explicit errors. Large line-coordinate indexing stops at the configured exact step budget or a cooperative cancellation boundary. Resume slices produce the same match and capture results as unsliced runs. Budget, output-limit and cancellation paths leave the immutable document snapshot and caller-owned cursor/repeat state unchanged.

## Limitations and next action

The evaluator covers VP-10/VP-16 positional and coordinate behavior, but this report does not claim search-command integration or command-level cursor/repeat recovery; T027 owns those command semantics. T026 can now reconcile the completed pattern-family evidence and run its integrated audit.
