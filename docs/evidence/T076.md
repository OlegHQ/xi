## Observable result

`AtomicCommandCoordinator` captures one immutable document snapshot and one shared parsed intent, resolves every active selection against that base, normalizes the combined edits, reduces mode/repeat/register state, and prepares candidate selections for the active and other views before publication. Identical edits are deduplicated; overlapping pure deletes are unioned; ambiguous inserts and replacements reject the entire command.

The document layer previews text edits without changing its live rope, EOL metadata, revision, history, or event stream. For a text-changing command, the coordinator installs the matching immutable workbench state immediately before one synchronous document commit. Document observers see the committed revision and matching active/mapped selections; nested document edits and state replacement are rejected during publication. A rejected document proposal restores the previous workbench state. One native undo restores the complete command batch. State-only selection/register/mode transitions do not publish text revisions, document events, or undo entries.

## Failure cases and recovery

`T076-MC03-DIFFERENT-INSERTS-01/02`, `T076-MC03-INTERSECTING-REPLACEMENTS-01`, `T076-MC03-DELETE-REPLACE-CONFLICT-01`, and `T076-MC03-INSERT-BOUNDARY-01` reject ambiguous edit batches before document or session publication. Injected faults at every preparation stage preserve the exact prior state pointer and publish no document event. `T076-MC03-REENTRANT-01` rejects an observer's nested edit; `T076-MC03-COMMIT-REJECT-01` restores prepared state after document validation fails. Cancellation after a yield and concurrent selection/document changes reject pending work without publishing its partial edits.
