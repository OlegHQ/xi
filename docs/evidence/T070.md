## Observable result

The language boundary now decodes native call and type hierarchy items, supports lazy incoming/outgoing and supertype/subtype expansion, assigns stable identities, bounds result size/depth, and marks recursive nodes as cycles. `HierarchyController` exposes loading, ready, unavailable, error, cancellation, and original-request restoration state with generation barriers.

Document links support unresolved `documentLink/resolve` responses. Only file and HTTPS targets without control characters or credentials can be returned by the explicit `openLink` action; no URI is executed as a shell command or written to the terminal. A bounded OpenTUI hierarchy surface renders capability state and cycle markers while the host retains expansion and opening ownership.

## Performance and visual evidence

Hierarchy requests are asynchronous and lazy; the UI presentation caps rows and does not perform requests in render callbacks. This ticket does not claim a keystroke-latency, startup, CPU, or memory-budget pass. Dedicated performance tickets remain unproven until their required measurements exist.

## Failure cases and recovery

- Recursive identities are marked with a cycle node and are not expanded recursively.
- A missing provider expansion capability returns an explicit `unsupported` state.
- Cancellation increments the generation, returns the original navigation request, and rejects late results as stale.
- Unsupported URI schemes, credentials, literal or encoded terminal controls, and unresolved targets are rejected before the host receives an open action.
- Malformed hierarchy items, links, ranges, regular-expression-free protocol data, oversized results, and excessive nesting fail with typed errors.

## Limitations and next action

T070 provides the language/UI read and request boundary. Application-specific host jump history and richer native command routing remain in T071; hierarchy expansion and link opening stay explicit host actions by design.
