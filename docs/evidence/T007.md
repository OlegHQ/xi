## Observable result

G0 has enough reproducible evidence to lock the stack and architecture choices in [T007 decision](../decisions/T007-g0.md): versioned UTF-16 document positions and a bounded chunked rope; a custom OpenTUI visible-row renderer with one-based conversion only at its terminal boundary; one OpenTUI terminal-byte decoder with canonical zero-based events and byte-preserving adapter requirements; and an owned Vim-pattern parser/evaluator strategy. The decision records the measured evidence, the numeric proxy differences, every unproven release budget, and the existing ticket owner for each unresolved incompatibility.

The buffer experiment supplies a real 1–10,000 batch/anchor-mapping scaling precursor. It does not model semantic selection sets, full Vim composition, history, rendering, or output. G0 therefore locks the kernel direction only; T089 and T062 still own full selection qualification. No prototype was copied into a production package, and there is no `apps/xi` runtime yet.

## Performance and visual evidence

T007 compares every target group and available proxy numerically in [T007 decision](../decisions/T007-g0.md). T002 screenshots were visually inspected at both target sizes. PTY protocol timings stop at event observation, and the renderer timings use synthetic mock key events; neither is physical key-to-photon measurement or release qualification. The T004 measurements are document/anchor kernels only. No Xi process exists for startup, loaded typing, service load, picker/search, pointer-to-frame, idle CPU, RSS, leak retention, or full multi-selection workloads, so all such budgets are explicitly unproven.

## Failure cases and recovery

- `INP-UTF8-CHUNK-LATE-01`: delayed continuation becomes fallback key events on the unguarded path; T035 owns production protection.
- `MP01-X10-RAW-HEX-01`: `1b5b4d20ffff` is UTF-8 re-encoded as `1b5b4d20c3bfc3bf`; T035 owns exact-byte preservation.
- `MP02-COORDINATE-OVERFLOW-01`: SGR input parses an unbounded coordinate; T085 owns versioned frame bounds.
- `MP01-SGR-RELEASE-01`: one renderer release causes multiple callbacks; adapter coalescing is pinned to OpenTUI 0.5.11 and requires a production regression test.
- `FC-T004-CANCEL-01` proves candidate-root cancellation leaves text/version unchanged; this is not selection-command cancellation evidence.
- `PATT-CATASTROPHIC-01` is bounded but synchronous in the spike; no interaction responsiveness claim is made.
- Neovim inventory, regex, input and pointer failures have named fixtures in the cited prerequisite reports; no discovered mismatch was suppressed.

## Limitations and next action

No product behavior or release gate is certified by G0. Only Linux ARM64 native loading is measured; terminal emulator/SSH/tmux forwarding, Shift bypass, other native artifacts, full Vim inventory, selection scale, service interactions and all end-to-end budgets remain open under T035, T061, T062, T085, T086, T089 and T094. G0 is the first feasibility checkpoint only. T008, “Establish package boundaries and lifecycle ports,” is the next dependency-ready ticket.
