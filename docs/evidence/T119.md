## Observable result

`bun run check:lint` runs a suppression audit and the real pinned Oxlint custom
rule against production packages/apps. `bun run check` includes this gate.
H1 owner defaults permit immutable results and numeric counters; explicitly marked
H0 kernels additionally reject loop allocation syntax. B scheduling checks reject
microtask-based CPU scheduling; C permits ordinary control code.

Single-code next-line exceptions require a known catalog budget and a concrete
reason of at least 20 characters. Unused exceptions fail. An independent AST
comment audit prevents native disable directives from disabling their own check.
Nested Oxlint configs cannot override the gate's explicit root config.

Production changes are limited to two H0 annotation comments in the rope's numeric
rank lookup and UTF-16 validation functions. No production defect was fixed, no
baseline suppression or production exception was added, and agentpack files were
preserved. This matches the user's explicit instruction to finish rules only.

## Failure cases and recovery

Initial development exposed two harness compatibility issues: TypeScript 7.0.2
has no legacy JavaScript AST API, so the independent audit now uses pinned Oxc
parser; Bun test types require explicit inclusion, supplied by the pinned test
types and a test-file reference. Both were repaired and rerun successfully.

A later run exceeded Bun's default 5-second per-test timeout in two groups that
launch multiple Oxlint processes (7 passed, 2 timed out). CLI fixtures now use one
Oxlint thread, and the test script allows 30 seconds per group. This is a tool
startup/test orchestration timeout, not an editor performance threshold. The full
suite rerun passed all 9 groups with 101 assertions in 20.65 seconds.

The current production findings are deliberately retained: 10 string-accumulation,
5 materialization and 2 microtask findings. T109 owns Vim findings, T111 layout/UI
input, T112 syntax scheduling, T116 workbench dispatch. Their backlog acceptance
now requires owned lint findings to be resolved and remediated H0 kernels classified.
No existing ticket/prerequisite was marked done to unlock this work.

## Limitations and next action

Classification is not inferred through the call graph. Two H0 kernels are seeded;
remaining H0 operations need annotations during owner remediation. Aliased calls,
dynamic property names, allocations in callees/native code, general string type
inference and full-document `slice` calls are not comprehensively detected. Quotas,
scratch lifetimes, immutable ownership and exception prose require review/tests
and the prescribed performance measurements. See [rule scope and examples](../../tools/lint/README.md).

The production gate remains **failed**, with every finding retained above. Run
`bun run check:lint` to inspect current findings; do not waive them in bulk. The
user specifically excluded fixing these issues from this change.
