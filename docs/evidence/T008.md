## Observable result

The repository now has public entrypoints for primitives, contracts, document reads, selections, layout, Vim session reads, workbench reads, services, platform adapters, UI composition, and the Xi composition root. Effectful facilities enter through typed process, asynchronous filesystem, clock, clipboard, and generic service contracts. Boundary JSON is decoded as unknown, UTF-8 validity is checked, and a caller-owned decoder must accept the resulting value.

The composition root injects platform, services, workbench, and optional UI dependencies. Nested disposable scopes unwind in reverse construction order on shutdown and partial startup failures. Terminal restoration is called before adapter disposal. The graph checker is wired into the existing public-boundary CI command; its negative fixtures reject Vim-to-UI imports, cross-module cycles, a circular service module, and a deep package alias. The UI package contains no OpenTUI import yet; the first renderer work remains in later tickets.

## Failure cases and recovery

Injected startup failures at each construction stage confirmed that all acquired resources are disposed in reverse order and the original startup error is preserved. The terminal-create case first registers a partial resource and then fails; its resource is disposed even though no adapter is returned. A failed terminal start and failed UI mount both invoke terminal restore before terminal disposal. A scoped signal subscription is removed when its owner scope is disposed; subsequent emits do not notify it and the subscriber count returns to zero. Circular imports between workbench/Vim files and between service modules are rejected by the graph checker.
