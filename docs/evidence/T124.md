## Observable result

Xi advertises only behavior that has a production handler. Completion snippets are now visible to servers. The client offers only UTF-16 positions, matching feature DTOs and edit conversion. Workspace-folder querying/changing and related diagnostic payloads are no longer advertised because Xi does not implement those handlers. Pull diagnostic refresh is handled as a server request and acknowledged after the supported refresh path runs.

Language providers now ask their session whether the server negotiated or dynamically registered the requested method. Missing and malformed providers return an explicit unavailable result without a JSON-RPC request. Dynamic registrations are selector-aware, capped at 64 active entries, reject malformed/unknown batches atomically, and publish change events. Selector globs compile at registration time. A valid unregister immediately removes availability. Sessions reject non-UTF-16 server position encodings, and retry exhaustion now transitions to `failed` instead of leaving initialization waiters pending.

## Performance and visual evidence

No end-to-end latency or visual claim is made by T124. The change gates asynchronous LSP feature requests and does not change ordinary document mutation, rendering, file loading, or terminal event processing. Dynamic registrations and selector sizes are bounded, and selector regular expressions are compiled when registration arrives. Native CLI latency and background-load qualification remain owned by T115 and are not certified here.

## Failure cases and recovery

- Fake peers that omit hover/completion, return malformed capability values, or advertise only partial providers caused no unsupported provider request; adapters returned unavailable.
- Unknown registrations and malformed registration batches left the active registration set unchanged. A mismatched unregister preserved the valid registration; a valid unregister removed it before the next provider call.
- A server choosing UTF-8 after Xi offered only UTF-16 failed initialization, exposed no provider, preserved the admitted document, and reached the terminal `failed` state with retry count zero.
- The first real T052 run exposed that Xi required optional `prepareRename` even when a server supported `rename`. The CLI now checks negotiated `prepareRename` support and uses the normal rename request when preparation is absent; the final T052 run passed and verified saved bytes.
