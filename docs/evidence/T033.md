These are local exploratory samples, not the release interaction budget; T062/T087/T089 own repeated scale, loaded-system, visual and performance qualification.

## Failure cases and recovery

The PTY driver waits for an OpenTUI readiness marker, sends the key stream in separate writes to preserve Escape framing, waits for the preview result marker, verifies the resulting bytes and verifies terminal restoration. The focused multi suites retain typed stale-document, stale-selection, conflict, cancellation, register-arity, incompatible-repeat, macro-failure, unmappable-history and selection-only-history failures. A preview failure exits nonzero and retains the raw PTY transcript for reproduction.

## Limitations and next action

This gate qualifies an engine preview only. It does not provide file open/save, a production terminal adapter, workbench layout, picker/services, language features, scale budgets or a packaged CLI. The first actual editor UI is T034, which depends on this gate and builds the OpenTUI workbench surface. Full Vim parity remains subject to the 597-row audit owned by T061 and the later release gates.
