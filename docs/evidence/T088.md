## Performance and visual evidence

The completion path performs work proportional to the selection set and proposed edits, then commits through the existing single workbench document coordinator. It does not copy a second document or scan the whole file. No performance qualification is claimed here; T106/T115 own the required 10,000-event and baseline measurements. The production PTY is functional evidence and does not measure output-to-photon latency.

## Failure cases and recovery

Moved or rotated selections change the generation and stale completion results are rejected by the existing request identity check. Different local replacement text, incompatible topology, and overlapping additional edits fail before `applyTextEdits`. Completion after cancellation cannot create a snippet session. A primary-only action is explicit through Shift+Tab/Shift+Enter and keeps the secondary selection set in the workbench.
