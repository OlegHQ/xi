## Observable result

Layout publishes each immutable visible frame together with a frame identity and hit map. Published frame identities, hit records, cell points, tagged targets and viewport anchors are immutable snapshots. A caller-supplied mutable viewport anchor is copied before publication and remains mutable without changing the frame. Hit results carry view, document version and layout generation, and return tagged text, fold, gutter, virtual-annotation or diff-filler targets. Text hits preserve UTF-16 boundaries, left/right affinity and tab virtual-cell intent across wrapping, horizontal scrolling, clipping and Unicode cell widths. Virtual annotations and diff fillers never expose editable text offsets. Gutter identity is derived from validated line and region coordinates. Invalid or stale nontext metadata is rejected before a frame is published; retained document-version bookkeeping is bounded by retained frames.

Stale frame IDs and document versions return typed cancellation failures instead of applying old row coordinates to changed text. The caller can cancel or hit-test a known current frame. The layout package does not infer Vim word, line, block or range semantics.

## Failure cases and recovery

Stale frame and document-version hits are rejected with typed layout failures. Resize invalidates the old frame hit map. Invalid, stale-version, duplicate, over-limit or out-of-bounds annotation/filler inputs fail before publication. Wide-glyph trailing cells snap to the leading UTF-16 boundary, and annotation/diff-filler cells cannot be interpreted as editable text offsets. Mutating a caller-owned viewport anchor after projection cannot mutate the frozen anchor retained by the frame or viewport cache.
