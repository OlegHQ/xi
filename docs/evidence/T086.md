## Observable result

OpenTUI is the sole terminal mouse decoder. Its versioned layout frame hit-tests editor cells and passes immutable text targets into the Vim-owned pointer gesture controller. Click, drag, double-click word, triple-click line, Alt add-caret, Alt-Shift block, wheel, edge scroll, pending-operator cancellation and lifecycle cancellation are routed through the production launcher. Pointer capture remains bound to the press view and frame until release or cancellation.

## Performance and visual evidence

Pointer dispatch is synchronous, frame-scoped and bounded to the published hit target; it does not scan the document or synthesize keyboard commands. Edge scrolling is event-driven and bounded to one viewport delta per motion event, with no continuous timer. No new visual screenshot matrix is required for this routing ticket; T087 owns selection-layer paint review.

## Failure cases and recovery

Cross-view and stale-frame events are rejected. Escape, focus/resize and disposal cancel capture without synthesizing a release. A pointer press cancels a pending Vim operator before placement. The production PTY verifies a lost release after resize leaves no stuck capture and the process accepts its keyboard quit path.
