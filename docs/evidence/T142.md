## Observable result

`:q` closes the current view and stays in Xi, including with no buffers remaining. `:q`
refuses to discard a dirty buffer's final view; `:q!` discards it. Shared views/comparisons
can close without losing the remaining document. `:qa` checks all dirty buffers and exits
only when clean; `:qa!` retains explicit discard behavior.

Closing a view restores a visible surviving leaf instead of focusing a hidden file tab.
Closing a buffer invalidates the layout cache and reconstructs a leaf if only hidden buffers
remain. Splitting a hidden view now fails before registering a phantom view or editing the
coordinator. Ctrl-W reaches the existing Vim window-prefix parser even with Git open;
continuations are not swallowed by the panel. Read-only comparisons no longer intercept
command-line input ahead of the router's command-line dispatch.

## Close lifecycle and dirty-comparison follow-up

`BufferHost.closeView` now owns Vim-session release, preview identity cleanup and last-view
notifications to document services. `:q`, comparison close, preview discard and the tab-close
fallback route through it. Closing a shared view keeps the authoritative document and its
services; closing its final view notifies owners/listeners exactly once. Preview cancellation
also checks document dirtiness, including edits committed outside the active Vim session.

The shared session close guard now permits closing one dirty view when another view retains
its document, while refusing a dirty final view. Comparison tab IDs no longer bypass that
guard. Coordinator state replacement completes before removing the view from its buffer's
view set. A view-close event releases comparison subscriptions, pending work and immutable
syntax snapshots immediately, including when `:q` closes the comparison.
