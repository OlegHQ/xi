## Observable result

`WorkbenchSession` owns the buffer registry, visible views, split tree, active focus and viewport positions. Each buffer owns one `TextFileDocument` and one `AtomicCommandCoordinator`; views in a split append immutable per-view engine state to that coordinator, so edits and the document undo tree are shared while selections and focus remain independent. Document change subscriptions map every live selection set through the committed change map, including edits and undo performed through the document boundary.

Preview buffers have a named slot. A clean, unpinned preview is replaced by the next preview; a dirty preview returns `dirty-preview-replacement` and remains open. Explicit pinning and the first successful text edit promote a preview. Closing a dirty buffer returns Save/Keep open/Discard choices; cancel and Keep open retain the document and active focus, while Discard removes only the requested view or buffer. Async close methods allow the injected save hook to complete before close.

Split geometry is immutable at the read boundary and has a configurable minimum pane size. Resize rejects a ratio that would make either pane smaller than the minimum. Layout persistence serializes workspace identity, buffer paths/flags, visible split structure and per-view scroll state without serializing recovery text or replacing document contents. Unknown layout fields, malformed identities, invalid ratios and missing restored buffers/views are rejected before state mutation.

## Failure cases and recovery

- `T038-DIRTY-PREVIEW-01`: replacing an already dirty preview returns `dirty-preview-replacement`; the old buffer, text and view remain present.
- `T038-MISSING-RESTORE-01`: a layout referencing an unavailable buffer returns `missing-restored-buffer` before changing open buffers or content.
- `T038-SPLIT-MIN-01`: a 60-cell split at ratio 0.9 rejects the 54/6 geometry with `split-too-small` and leaves the prior ratio installed.
- E02 cancel leaves the dirty shared buffer open and focusable; a later explicit discard removes only the selected split view and preserves the source content.
- External committed changes and shared undo map each live view through one versioned change map; stale selection versions are never silently reused.
