## Observable result

The pattern evaluator now handles composing clusters according to pinned Vim behavior. Modern selectors accept required combining marks independent of order and allow extra marks; selector 1 preserves its observed exact ordered literal behavior. A plain literal does not match an attached composed cluster. Dot consumes an attached cluster for every selector, while the old engine's simple class keeps a base-only span. A bare combining literal matches an attached base cluster and rejects a detached leading mark. Precomposed characters remain distinct from decomposed base-plus-mark sequences. `\Z` and `\%C` are checked directly across selectors 0, 1 and 2.

The oracle harness can load a raw-byte fixture into a real Neovim buffer. T100 uses that path for `a\0bx😀y`, then searches with `\%d0`, `\%d0\%d98` and `\%U1F600`; no Lua string literal or `matchstrpos()` call carries NUL. The observed Neovim start/end positions are checked in UTF-8 byte columns and converted to Xi's UTF-16 snapshot spans at valid scalar boundaries. Valid codepoint pattern source spans and an invalid Unicode scalar's source-aware error span are also asserted.

## Performance and visual evidence

Visual evidence is not applicable to the pure pattern evaluator. The stress benchmark measures in-process work and asserts deterministic bounds; it does not claim an interactive latency target, event-loop scheduling behavior or representative natural-language performance. Latest run: 20,001 UTF-16 units completed in 20,007 evaluator steps; the adversarial 5,001-unit cluster failed at the exact 1,025th step against a 1,024 budget. The raw JSON artifact is `.artifacts/bench/vim/t100-composing.json`.

## Failure cases and recovery

The retained matrix covers detached versus attached combining marks, precomposed mismatch, extra and reordered marks, old-engine differences, NUL and supplementary code-point boundaries. The evaluator's budget failure is deterministic across repeated runs, keeps the literal source span, yields while scanning marks, and responds to cancellation during a composing-cluster scan. Invalid `\%U110000` compilation returns `invalid-pattern` with source span `{ start: 0, end: 9 }`.

## Limitations and next action

No T100 acceptance item remains unmet. The current repository-wide check passes. The direct buffer oracle uses Neovim 0.12.4 only during development; production has no Neovim process, library or remote dependency. `searchpos(..., 'e')` reports the byte column of the last matched scalar, so the test translates the emoji result to a half-open byte span using its known four-byte UTF-8 width.
