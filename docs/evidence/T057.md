## Observable result

`parsePorcelainV2Z` decodes machine-readable NUL-delimited Git status records, retaining staged/unstaged/conflicted state, rename source paths, untracked/ignored entries and repository generation. `GitStatusCache` rejects late refreshes and never treats unsaved text as a stageable disk state.

## Performance and visual evidence

Parsing is a single pass over bounded protocol records and cache publication stores immutable metadata. Diff rendering remains a downstream UI owner.

## Failure cases and recovery

Malformed UTF-8/records return typed failures. Stale generations cannot replace a newer snapshot. Conflict records are explicit and cannot be mistaken for resolved text.
