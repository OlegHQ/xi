## Observable behavior

Each split leaf reserves a header row. Solid chrome and tab pointer targets use the same
geometry as editor projection, including nested horizontal/vertical layouts. Each strip reads
its own active view's tabs rather than the global active tab. Hover targets include pane
identity. Tab control events carry the originating view to the workbench callback.

Ordinary file activation targets the clicked pane. A buffer already visible in another pane
gets a new view in the target pane, sharing its document/history; its original view stays put.
BufferHost creates the corresponding Vim session when needed. Ordinary file close controls
route through the existing guarded :q handling for the selected pane. Comparison tab handling
still follows the original comparison-specific path and requires follow-up (below).
