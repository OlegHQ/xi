Found while stabilising the e2e suite (pre-existing at c6a3cd2, reproduced on a HEAD binary built in a detached worktree): when a stalled read delivers ESC and the next byte together, OpenTUI 0.5.11 yields a nameless key for ESC + non-alphanumeric (`ESC:`) and a meta chord for ESC + alphanumeric, and Xi dropped both, so `iX<Esc>:q` typed `:q` into the buffer. Fixed in the UI adapter (`packages/ui/input/coalesced-escape.ts`: split into Escape + key before dispatch) and in the session (unmapped Alt/Meta chords act as Escape then key, Neovim `i_ALT`). Probe: sending `ESC:` in one write now opens the `:` prompt on the compiled binary (scratchpad/esc_colon.py); first-key frame latency after READY is unchanged versus HEAD (per-key 2–8 ms, Escape 23–77 ms because of the parser's fixed 20 ms timeout).

Ownership: `main()` went from 928 lines / 36 mutable slots to 136 lines / 0 (`apps/xi/src/wiring/*`, `cli.ts`, `lifecycle.ts`); ARCH-COMPOSITION-ROOT-01 now enforces ≤200 lines / 0 `let`. ## Performance and visual evidence

Keystroke path audited and left synchronous (drainKeys → microtask flushFrame → single render; the redundant second OpenTUI frame per key is removed, T111 render-scheduling fixtures pass). Held-key PTY measurement before changes: p50 1.6 ms / p95 3.5 ms / max 7.3 ms end to end at 30–200 Hz, no backlog. LSP full-sync flush and crash-recovery checkpoint now yield every ~4 ms (measured 4–5.5 ms max step at 8–10 MiB, versus 6–30 ms single-shot before). `makeNormalSelection` is O(1). Visual: contrast fixtures extended to token-under-cursor and cursor-on-selection for light, dark and ASCII themes; sidebar/tab frames inspected in tests/ui/sidebar-tabs.test.ts and t034/t063 matrices. Not re-measured: the full 15-keystroke-latency gate and Neovim-paired startup comparison (unchanged code paths; remains the release gate's job).

## Failure cases and recovery

Journal retry no longer deletes a copied source; restored journals are not re-executed; trash steps precede renames; invalid journals are rejected deeply. Restore onto an externally recreated path refuses with a "recreated externally" message. LSP restart during backoff resolves; activation during backoff does not spawn a second process; edits during replay stay in version lockstep. Save cancels and awaits a pending checkpoint. Uncaught exceptions restore the terminal and exit non-zero. Esc during a `/` prompt or a register prompt restores state; `<C-v>` literal codes terminated by any key replay that key.

## Limitations and next action

- Config bindings resolve single-key tokens only; multi-key chords fall through to Vim.
- Sidebar width is in-memory (not persisted across sessions).
- `#` register uses the previously active buffer; Ctrl-^ itself is not bound.
- Preview tab replacement honours the dirty-preview rule (a dirty preview is kept and a second preview opens).
- Keystroke-latency and startup gates were not re-run under docs/plan/05 procedures in this pass; the affected paths did not gain awaits or scans, but the gate remains unproven until rerun.
- Changes are uncommitted on `dev`; commit was not authorized in this session.
