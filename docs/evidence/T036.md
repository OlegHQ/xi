## Observable result

`packages/services/config/index.ts` owns a boundary parser for the TOML used by Xi configuration, language-server/language and theme files. It produces filename, line, column and path diagnostics for malformed syntax, duplicate keys, unknown schema fields, wrong values, unknown commands, normalized binding collisions and native Ex alias collisions. Parsed data is validated before it becomes an immutable compiled configuration.

Compilation layers defaults, user, selected profile, workspace and CLI sources with deep table merge, replacement scalar/array behavior and field-level provenance. `ConfigStore.reload` compiles the complete candidate and atomically publishes one new generation; a rejected reload leaves the exact prior snapshot available. Captured generations provide a small stale-sequence check for dispatch owners. Untrusted workspace layers may retain appearance settings but cannot introduce executable server/formatter settings until explicitly trusted.

The Xi profile includes the required selection, mouse, motion-trail, hint and cursor settings plus the command declarations from the plan. `config/default.toml`, `config/languages.toml`, `config/themes/xi-light.toml` and `config/personal-migration.toml` are complete examples. Strict compilation excludes profile-personal aliases and forces motion trail off; the personal profile retains the migration aliases without changing stable command IDs.

## Performance and visual evidence

This ticket has no rendering or keystroke latency budget. Config compilation is bounded by input size and key/language entry counts, does not perform filesystem/process work, and publishes immutable data only after validation. Executable trust is checked before publication.

## Failure cases and recovery

- `T036-FAIL-DUP-01/02`: `space` and `Space` leader tables normalize to one `<Space>` sequence and reject a duplicate binding.
- `T036-FAIL-UNKNOWN-01/02`: an unknown editor field is rejected with its source line and path.
- `T036-FAIL-EXEC-01/02`: an untrusted workspace language-server command is rejected with `untrusted-executable-change`; the lower last-good config remains usable through `ConfigStore`.
- `T036-RELOAD-04/05`: a malformed/unknown reload does not replace the prior immutable snapshot object.
- `T036-FAIL-SYNTAX-01/02`: malformed table syntax fails with the named source file.
- `T036-FAIL-LANGUAGE-01` and `T036-FAIL-THEME-01`: language schema fields and six-digit theme colors fail closed.
- `T036-PROFILE-02/03`: strict has no personal aliases and no motion trail after compiling alongside the migration layer; personal retains the reviewed aliases.
