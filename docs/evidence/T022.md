## Observable result

`packages/vim/insert/index.ts` is a pure planner for insert, replace and virtual-replace sessions. It emits immutable, versioned document plans and keeps no second text store. It supports entry/count behavior, open-line indentation, configured Backspace, Replace restoration, virtual-cell replacement, undo grouping/breaks, Ctrl-O suspension, literal and digraph input, opaque UTF-8 paste, and separate Escape/Ctrl-C exits. Entry `gi` uses the explicitly supplied last-insert document/version/cursor when present and falls back to the current cursor when no prior Insert location exists, matching the pinned oracle; `gI` enters at the line start. Exit transitions expose `lastInsertCursorOffset`, the post-count/post-cleanup insertion boundary, so the caller does not mistake the Normal-mode cursor for the saved Insert location.

CR digraph edits carry `textIntent: 'literal-control'` to the document owner, including counted replay and Replace restoration when they contain literal CR. Enter and generic paste retain their ordinary LF normalization behavior. T101 remains the owner of the document/fileformat contract and storage implementation.

Ctrl-R is a typed handoff. The planner requests a register name from the register owner, returns a versioned request with document and cursor identity, and accepts literal text only for that pending request. It performs no register lookup. The focused handoff fixture compares insertion from a named register against Neovim; empty owner payloads represent an absent register without editing, and intervening document changes make the request stale.

`packages/vim/insert/default-digraphs.ts` contains all 1,366 mappings returned by Neovim 0.12.4 `vim.fn.digraph_getlist(1)` under `--clean -u NONE`. The live test compares the complete ordered table and values, uniqueness, and lookup behavior to the pinned oracle response. The response SHA-256 is `6a3ff12c7e3d6bdfd471fa5fe0b1a661bd235f2e06e259c7f720287357a8a789`.

The focused suite passes 40 pinned-Neovim insert/replace differentials, including positive `gi`/`gI` and counted `gi` re-entry, counted insertion, Escape/Ctrl-C, undo grouping, indentation/Backspace, Replace restoration, Virtual Replace over tabs/wide glyphs, Ctrl-W/U/T/D/O, literal input and default digraphs. It also checks the full static digraph table, Ctrl-R handoff/staleness, malformed paste, option/count failures and active-line-only reads on a 5,000-line document.

The pinned Neovim 0.12.4 table query returns `"\n"` for both `NU` and `LF`, but the sequence must be retained through insertion resolution: `T022-DIGRAPH-DEFAULT-NU-ORACLE-01` and `T022-DIGRAPH-DEFAULT-LF-ORACLE-01` feed `i<C-K>NU<Esc>` and `i<C-K>LF<Esc>` to the oracle and compare the live `nvim_buf_get_lines()` result. Both produce an in-line NUL (`["\u0000ab"]`) in that API observation. Xi resolves both sequences to U+0000; the checked-in static digraph table remains byte-for-byte equal to `vim.fn.digraph_getlist(1)`.

The NU fixture checks persistence through the text-file boundary: Xi serializes the live buffer as bytes `[0x00, 0x61, 0x62]`; reopening those bytes returns a `binary-content` read-only document and preserves the exact bytes, matching T010's raw-NUL policy.

`T022-DIGRAPH-CR-MODEL-GAP-01` now serves as a regression fixture for the resolved model gap. With initial Neovim lines `["ab"]`, `i<C-K>CR<Esc>` yields `["\rab"]` through the pinned 0.12.4 live `nvim_buf_get_lines()` API: CR remains same-line content. Xi matches that line result, serializes `[0x0d, 0x61, 0x62]`, and explicitly reopens it with `fileFormat: 'unix'` as editable same-line content with identical bytes. Strict `fileFormat: 'auto'` returns `ambiguous-line-endings` read-only and preserves the exact bytes. This uses T101's explicit fileformat policy; no-options legacy behavior remains unchanged.

## Failure cases and recovery

`T022-BACKSPACE-START-DENIED-01` and `T022-BACKSPACE-START-ALLOWED-01` cover Backspace at the original insertion boundary; `T022-REPLACE-TAB-01` and `T022-VREPLACE-TAB-01` cover Tab replacement; counted insertion is covered by `T022-INSERT-COUNT-I-01`, `T022-INSERT-COUNT-A-01`, `T022-INSERT-COUNT-O-01` and `T022-INSERT-COUNT-CAP-O-01`. Replace restoration is covered by `T022-REPLACE-BACKSPACE-RESTORE-01` and `T022-REPLACE-BACKSPACE-ALL-01`. `T022-DIGRAPH-CR-MODEL-GAP-01` now verifies the live CR result and round-trip policy; the NU and LF oracle fixtures continue to pass.

## Limitations and next action
