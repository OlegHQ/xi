## Observable result

Xi's last-motion setting produces a static faint highlight from each source through destination character, with complete UTF-16 character endpoints. Explicit Normal `v` adopts that same immutable characterwise selection; Normal operators still work from the Normal cursor. `V`/Ctrl-V and strict/off `v` keep existing semantics. Forward/reverse direction and multiple member identities are preserved. Edits, failed/no-op motion, mode transitions, pointer/host placement, panel commands, terminal blur and disposal invalidate the preview. UI consumes only versioned engine ranges; no text store or motion semantics were added to widgets.

The existing presentation port now combines workspace-search highlights and motion previews with stable cached identities. Custom themes derive a faint trail from their background/selection colors. Mode transitions notify the status chrome, fixing a stale NORMAL label while selecting.

## Failure cases and recovery

A test initially expected G to land at the last character; corrected to the existing last-line cursor semantics. Multi-selection setup initially omitted the documented `xi` Ex prefix; corrected the fixture. Empty Unicode boundaries and reverse ranges use the shared selection owner, then Visual edits use the existing operator normalizer. Strict mode is checked independently of ghost adoption.
