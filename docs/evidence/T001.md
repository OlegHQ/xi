## Follow-up correction from T002

The original `check:toolchain` looked for an `opentui` executable under `node_modules/.bin`, which is not the OpenTUI core runtime artifact. T002 reproduced the false “missing” result while `@opentui/core@0.5.11` and `@opentui/core-linux-arm64/libopentui.so` were installed and rendering successfully. The check now verifies the pinned core package, discovers the native library, and loads it through `resolveRenderLib().getBuildOptions()`. The required-present check passes; a nonexistent `XI_OPEN_TUI_ARTIFACT` override fails as expected. This report was refreshed to remove the stale claim that the native runtime is absent.
