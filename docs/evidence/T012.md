## Observable result

`TextFileDocument` now records commits in a bounded, branch-preserving history tree. Explicit undo groups combine multiple transactions into one undo step; changes from another origin close the current group and create an independent step. Undo and redo return the associated inert before/after serialized selection values. Those values are validated, cloned, and frozen by primitives as bounded JSON data, so document history does not import Vim or selection-feature code.

History replay applies inverse/forward edit deltas and line-ending metadata patches through the normal document owner. It restores revision identity while document versions continue to advance, so saved/modified state follows the active branch. The versioned archive stores the tree, edit deltas, selections, branch state, saved identity, and a fingerprint of the exact current file bytes. Import validates the archive schema, checksum, graph and edit chains, selection values, and content fingerprint before changing the document. Retention is capped at 256 entries and 33,554,432 UTF-16 units of retained edit text; pruning advances the checkpoint while preserving history newer than it. Edits retain deltas rather than whole-document snapshots.

## Failure cases and recovery

`T012-GROUP-INTERRUPTION-01` confirms an external LSP-origin edit closes an active Vim group and each resulting history entry undoes independently. `T012-CORRUPT-HISTORY-01` confirms checksum mismatch and malformed serialized JSON leave text, version, current revision, and history untouched. `T012-PERSIST-ROUNDTRIP-01` confirms a valid archive loads only against matching document identity and exact file bytes, and preserves line-ending metadata across replay. `T012-SELECTION-VALUE-01` confirms unsupported or oversized selection data is rejected before a document commit mutates state.
