Git row formatting, with normal/selected/hover rows, path metadata and status glyphs.
It compares the legacy menu surface mapping against the new sidebar mapping with the same
current formatter; it is not a binary/revision performance baseline. Current matrix has
827 versus 225 sampled spans below 4.5:1. It is diagnostic, not an all-theme pass.

terminal-palette coverage remains required. Themes are read from the provided directory;
none is rewritten. Fixtures contain synthetic paths/content, not private workspace data.

## Full WorkbenchApp scene audit and readable UI text mapping

Added `tests/ui/workbench-theme-scenes.ts` and `workbench-theme-audit.ts`. The audit mounts
production `WorkbenchRenderable` plus `WorkbenchApp`, rather than reconstructing panel
colors from theme tokens. Every scene asserts that populated sample content actually
appears. It covers Files, Search, Git, picker, Problems, Outline, Hierarchy, Hover,
Completion, Signature, directory review, task output, Ex command line, prefix help, context
menu, unified comparison, side-by-side comparison and status messages (18 scenes).
It captures normal/selected rows and moves the pointer over normal sample rows for hover
captures where present. Real per-view buffer-tab callbacks and editor chrome are included.

The first expanded run exposed a correlation that the earlier Git-only audit missed:
Latte's `ui.menu` foreground on `ui.menu` background was 2.56:1, selected Search text on the
selection background 4.39:1, buffer-strip text 3.73:1, and status-line text 2.34:1.
Source menu scopes are suitable popup surfaces but their low-contrast foregrounds are not
suitable for Xi's persistent/navigation text. The earlier Git-only claim must not be read
as full-workbench contrast qualification.

`readableTextColor` now preserves adequate RGB text, otherwise reuses a readable surface
foreground, otherwise chooses black/white. It runs after row/segment/state style composition,
and also applies to sidebar tabs, buffer strips, status-line labels and status messages.
Color-pair results are bounded/cached; no source Helix token tables/files are rewritten.
Original text modifiers and terminal indexed/default intent remain intact. Sidebar source
styles are still the same object. Popup/menu backgrounds retain their authored colors;
only persistent sidebar surfaces use editor-background mapping.

Rendering every theme also found raw terminal-color sentinels falling through row fallback
colors (and border/theme defaults) into OpenTUI's RGB parser, which emitted magenta fallback
warnings. All row fallback channels now pass through the renderer's existing `themeColor`
conversion. The regression fixture verifies a raw indexed row foreground retains indexed
intent and slot 15 in the actual rendered span.
