## Observable result

The headless and PTY oracle harnesses install a disposable fixture-local provider
for the `+` and `*` registers immediately after fixture decoding and before any
capture. The provider stores copied lines and register types in isolated Lua
state, seeds each fixture independently, and never consults the host clipboard.
The process environment also prepends executable sentinel stubs for the supported
OS clipboard commands. The harness fails if any stub is invoked, while clearing
personal Vim configuration variables and launching Neovim with `-u NONE -i NONE
--noplugin`.

T121 adds a shuffled and repeated headless matrix with two sanitized clipboard
seeds and two fake external-clipboard variants. It checks complete line and
register snapshots, independent `+`/`*` contents and types, unnamed-register
interactions, explicit paste results, UI startup state, and terminal restoration.
The PTY capture now includes `"`, `+`, and `*` registers so UI initialization is
observable.

## Failure cases and recovery

Before isolation, replayed snapshots exposed host-dependent `+`/`*` register
contents. The harness now places the provider before the first capture, uses a
fresh temporary root per invocation, and fails on any sentinel executable call.
The explicit copy/paste and register-type assertions preserve the mismatch
surface instead of masking it with partial snapshots.
