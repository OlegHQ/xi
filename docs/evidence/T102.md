## Observable result

`packages/vim/motions/structural.ts` resolves versioned structural motions against immutable `DocumentSnapshot` values. It validates stale cursors/counts and a configurable UTF-16 scan budget, parses Vim `matchpairs`, matches nested delimiters in both directions, resolves sentence and paragraph boundaries, computes counted percentage addresses, and recognizes section macros. It returns immutable cursor outcomes without changing document text or version.

`resolveVimStructuralMotion` and its typed cursor/invocation/options/failure/outcome contracts are exported through `packages/vim/src/index.ts`. Ticket-specific pinned fixture metadata is retained in [t102-structural.json](../compatibility/t102-structural.json).

## Performance and visual evidence

No separate latency or rendered-visual budget was measured. Structural reads select a contiguous line window around the cursor using line-start lookups, reject oversized windows before slicing, and scalarize only the selected text. `maxScanUtf16` (default 1,000,000 UTF-16 units) bounds both text slices and scalar materialization; resolutions exceeding it return `scan-limit` without a full-document read. No keystroke-path latency claim is made.

## Failure cases and recovery

- `T102-STRUCT-PERCENT-NESTED-01` and `T102-STRUCT-PERCENT-CLOSING-01` cover nested and reverse delimiter matching; unmatched delimiters return `unmatched-structure` without mutation.
- `T102-STRUCT-PERCENT-CUSTOM-PAIR-01` exercises a custom `matchpairs` option.
- `T102-STRUCT-PERCENT-COUNT-02` covers an explicit counted percentage address.
- Sentence/paragraph fixtures cover punctuation, blank-line and EOF boundaries; section fixtures cover `[[`, `]]`, `[]` and `][`.
- Invalid count, stale document version and exceeded scan budget are asserted as typed failures before any outcome is published.
