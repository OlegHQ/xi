## Observable result

`startLanguageTransport()` launches through Xi's typed `ProcessPort`, adapts async stdout/stdin streams to the maintained LSP 3.17 JSON-RPC connection, and exposes request, notification, server-request, initialization and shutdown APIs. The framing reader validates byte-counted `Content-Length`, incrementally handles partial and coalesced frames, rejects invalid UTF-8/JSON/JSON-RPC envelopes and bounds allocation before reading a body. JSON-RPC request IDs are tracked to reject unknown and duplicate responses; cancellation sends `$/cancelRequest` and rejects the local caller promptly. Shutdown and process termination use bounded deadlines.

Default limits are an 8 KiB header, 8 MiB body, 1,024 active/cancelled requests, 30-second request timeout, 2-second process-exit wait, 500 ms force-after interval and 64 stderr metadata records. Hard ceilings are 64 KiB headers, 64 MiB bodies, 10,000 requests, timer-safe deadlines and 1,024 stderr records. Stderr payloads are never retained: diagnostics keep only byte counts and a bounded list of chunk sizes, so document text is not copied into logs. The architecture checker grants the two pinned protocol packages only to `packages/services/language/`; `ARCH-LSP-OWNER-01` proves that Vim and another services feature cannot import them.

The dependency probe installed and imported the maintained packages with the pinned Bun runtime. A memory-backed common JSON-RPC adapter and the browser entrypoints both completed a request/response containing `λ` without Node stream or VS Code extension-host APIs. Since those libraries worked, this implementation uses their JSON-RPC/LSP dispatch and owns only the bounded process framing adapter.

## Failure cases and recovery

Fixture IDs: `LSP-T046-SPLIT-UTF8-COALESCED-01`, `LSP-T046-BIDIRECTIONAL-REQUEST-01`, `LSP-T046-UNKNOWN-METHOD-01`, `LSP-T046-MALFORMED-JSON-01`, `LSP-T046-OVERSIZED-FRAME-01`, `LSP-T046-EOF-MID-BODY-01`, `LSP-T046-DUPLICATE-RESPONSE-01`, `LSP-T046-CANCEL-REQUEST-01`, `LSP-T046-STDERR-FLOOD-01`, `LSP-T046-PROCESS-LIFECYCLE-01`, `LSP-T046-SHUTDOWN-ESCALATION-01` and `LSP-T046-SPAWN-FAILURE-01`.

An early suite run stalled at the duplicate-response fixture because the fake process's stdin write awaited the peer's delayed response handler. The fixture was corrected to model a process pipe: delivery returns after bytes enter the peer, while peer responses proceed asynchronously. The same run exposed that JSON-RPC sends cancellation notifications without locally rejecting its request promise. The Xi adapter now races cancellation locally, guards cancellation after connection disposal, and the full suite passes. Malformed frames and unexpected EOF move the transport to `failed`; graceful shutdown reaches `stopped`, while an unresponsive server is terminated after the configured deadline.
