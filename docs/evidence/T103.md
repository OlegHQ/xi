## Observable result

`packages/vim/operators/text-transform.ts` prepares one versioned, atomic `DocumentEdit` transaction for case operators `gu`, `gU`, `g~`, join operators `J`, `gJ`, indentation operators `>`, `<`, and provider-backed `=`/`gq`/`gw`. Characterwise, linewise and blockwise normalized ranges are accepted for case transforms; linewise joins trim joining whitespace and honor `joinspaces`; indentation honors `shiftwidth`, `tabstop` and `expandtab`.

Formatting and equalization use injected typed providers. A missing provider returns `{ kind: 'provider-unavailable', provider: 'indent' | 'format' }`; provider failures, cancellation, malformed UTF-16 and out-of-range/overlapping edits fail before a document transaction is returned. `gw` carries a preserve-cursor intent, all plans carry one single-command history boundary and no register write, and every nonempty plan retains the source document ID/version.

The public contracts and planner are exported through `packages/vim/src/index.ts`. Neovim behavior is pinned in [t103-oracle-traces.json](../../tests/vim/operators/t103-oracle-traces.json), with fixture catalog [t103-fixtures.json](../../tests/vim/operators/t103-fixtures.json).

## Failure cases and recovery

`T103-PROVIDER-01/02/03` prove that `=`/`gq`/`gw` do not guess when indentation or formatting providers are absent. `T103-PROVIDER-07` rejects an unpaired surrogate before commit; `T103-PROVIDER-08` cancels after provider return. `T103-FAILURE-01/02/03` reject stale versions, invalid options and empty ranges before producing edits. Provider edits are range-bounded, sorted, non-overlapping, surrogate-safe and require `textIntent: 'literal-control'` when carrying CR content.

## Limitations and next action

The pinned formatter rows document Neovim's oracle output while Xi's `=`/`gq`/`gw` integration remains provider-owned; the planner reports provider absence explicitly and does not embed a syntax or formatting engine. Workbench command dispatch and provider registration remain downstream integration work. No T103 acceptance item in the operator planner contract is unmet.
