## Observable result

`packages/vim/macros/index.ts` provides immutable macro-register storage, recording sessions and deterministic execution through a caller-supplied parser dispatcher. Recording accepts raw user keys and semantic macro-call tokens while suppressing mapping expansions and replay-originated keys, so a mapped key is recorded once and is remapped once when replayed. Macro registers retain their name, token vector, token count and generation metadata.

Execution supports nested `@{register}` and `@@` tokens, cross-call last-register state, count-leading replay, recursion/depth detection, repeat/work budgets, cancellation checks and deterministic slice callbacks. Each dispatcher callback is one atomic command; a callback failure, cancellation, recursion or budget error stops execution and returns committed/consumed counts without claiming a half transaction. Register-vector values are not accepted as executable macro text.

## Performance and visual evidence

No rendering threshold applies to the pure macro state/executor. Playback checks cancellation at every token and calls the optional deterministic slice callback at the configured bound; no asynchronous process or filesystem work is introduced.

## Failure cases and recovery

`T025-FAILURE-01` detects recursive register calls before dispatch. `T025-FAILURE-02/03` cancels between atomic callbacks and retains one committed command. `T025-FAILURE-04` stops on a synthetic dispatch failure with prior commits counted; `T025-FAILURE-05/06` rejects a count over the configured repeat limit before dispatch. Empty recordings, malformed tokens, missing registers and invalid register names return typed failures. Mapping expansions and macro-originated input are ignored while recording to prevent double capture.

## Limitations and next action

The workbench/parser dispatcher must connect `q`/`@` parser intents to the recording and execution APIs; command wiring and multi-cursor macro policy remain downstream owner work. No T025 acceptance item in the macro owner contract is unmet.
