## Observable result

`packages/ui/src/solid/workbench.tsx` composes command line, picker, completion, signature, hover, prefix help, context menu, directory review and Git diff as Solid `RowsSurface` instances. Cursor-relative bounds remain in `packages/ui/src/solid/layout.ts`; pointer events forward to existing semantic controllers with their generation and capture rules. `WorkbenchInputRouter` remains the sole keyboard focus/ordering owner.

`packages/ui/src/terminal.ts` no longer installs individual overlay renderables, visibility setters or per-surface disposal chains. The only remaining native UI renderable is the editor viewport.

## Failure cases and recovery
