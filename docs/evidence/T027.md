## Observable result

`packages/vim/search/index.ts` provides immutable, snapshot-bound search previews. A preview resolves forward/backward search, `n/N`, wrap/no-wrap, search offsets, word searches (`*/#`, `g*/g#`), and operator-search target ranges without mutating the cursor or committed repeat state. Work is resumable through the pattern evaluator; cancellation returns the original view/state, and commit rejects a changed document id/version.

The substitute planner parses `:s`/`:substitute` delimiters and flags, reuses an empty pattern from the committed search state, selects the current line or an explicit line range, supports first-per-line/global/count-only/confirm modes, expands captures and Vim replacement escapes, and emits sorted versioned edits with one deterministic undo group. Replacement expansion covers `&`, `\\0`–`\\9`, escaped literals, `\\r` newline, `\\n` NUL, `\\t`, `\\u/\\l/\\U/\\L/\\E`, and previous replacement `~/\\~`. Case flags `i` and `I` are propagated to the Vim pattern compiler.

## Failure cases and recovery

Empty search/substitute patterns return a typed `empty-pattern` failure unless a committed pattern is available for reuse. A no-wrap search reports `no-wrap` while preserving the view. A cancelled preview restores its original cursor/scroll/search state and reports the evaluator cancellation on resume. Commit against a changed document id/version returns `stale-snapshot`. Unknown or duplicate substitute flags, malformed delimiters, unsupported replacement escapes and missing confirmation callbacks return typed failures before edits are produced. Zero-width and multiline matches advance through evaluator consumption and produce finite plans. Operator search returns a versioned inclusive range for the downstream range normalizer.
