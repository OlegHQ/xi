## Observable result

`sidebar.toggle` is in the config command catalog and default Space s bindings for normal,
Files, Search, Git and diff-panel contexts. The controller owns explicit visibility while
retaining its width. Layout caches include visibility, so hiding reclaims the editor area;
sidebar row surfaces stop rendering. Hiding dismisses panel focus and allows immediate
editor input. Showing restores the previously visible Files/Search/Git panel within the session. Explicit Files/Search/Git open requests reveal
the sidebar through their shared controller open hooks.

Startup reads optional ~/.xi.toml after ~/.config/xi/config.toml and languages.toml. It is a
normal config override layer, including key mappings and `[editor] sidebar-visible = false`.
Visibility is validated as Boolean; malformed UTF-8 reports a diagnostic. Visibility changes
queue serialized atomic writes, coalescing pending toggles; shutdown flushes the queue.
No personal ~/.xi.toml was created or altered; tests use disposable HOME directories.

unrelated settings and comments for ordinary [editor] and dotted-key configurations, accepts

state. It recognizes the real platform's ENOENT as missing (the initial fake used not-found).

## Inline-state and leader-remapping follow-up

The inline-table limitation above is now fixed for the supported TOML grammar.
`patchInlineTableBoolean` reuses the parser's quote/depth helpers and masks comments with
spaces to preserve character offsets. Existing Boolean tokens are replaced in place; absent
ones are inserted before the closing table brace. Fixtures cover quoted keys, nested tables,
commas/braces/hash characters inside strings, multiline tables with misleading comment braces,
empty tables and existing settings. Unrelated bytes/comments remain unchanged. Added-value
fixtures also parse with Bun's TOML parser. Invalid editor scalars/Boolean values are rejected.

Leader routing no longer hard-codes `v` or falls back to hidden shortcuts. It matches arbitrary
configured key-sequence prefixes and executes only declared mappings. Panel bindings override
conflicting normal bindings; remaining normal bindings are inherited for global actions.
Prefix help uses this same effective binding set. Existing implicit Space q macro-record,
Space c config picker and Space v p problems bindings are now explicit defaults with command
IDs (38 declarations total). Native register input after macro.record remains native data.
Single-key and panel-internal shortcut remapping/registry discovery still require the broader
audit; this does not claim all additional commands are now configurable.
