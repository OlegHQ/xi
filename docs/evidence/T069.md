## Observable result

Xi now decodes the LSP `insertTextFormat` field, expands bounded numbered placeholders, nested defaults, choices, mirrors, final `$0`, and regular-expression transforms. Unsupported variables and malformed transforms return typed failures before mutation.

Completion insertion goes through `WorkbenchSession.applyTextEdits`. The launcher closes any active Vim Insert group, opens one service undo group, applies the completion and additional edits atomically, and retains that group while snippet fields are edited. Placeholder navigation changes the selection generation and reanchors the snippet. External document changes cancel the snippet, while owned snippet replacements update the Vim Insert session and all live views through the shared change map.

## Performance and visual evidence

No new visual surface or continuous render loop is introduced. Snippet expansion is bounded to 256 KiB and 10,000 tabstop occurrences; Tab movement is O(1), and anchor mapping uses one sorted edit batch. T069 does not claim a keystroke-latency or memory-budget pass; those remain covered by the performance catalog and their dedicated tickets.

## Failure cases and recovery

- Nested placeholders and nested transform formats are parsed with exact UTF-16 ranges.
- Unsupported variables, invalid regular expressions, incomplete constructs, and overlapping mirror edits fail before document mutation.
- Stale or disposed snippet sessions return typed failures.
- Any external document change cancels the snippet and retains the committed document text; Vim Insert session offsets and views are mapped through the same document change.
- Completion edits are rejected when stale, outside the current document, invalid, or overlapping; no direct document mutation bypasses the workbench coordinator.
