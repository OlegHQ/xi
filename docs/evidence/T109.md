## Observable result

Normal horizontal motion and nonblank line motions use bounded UTF-16 source windows on printable ASCII lines. Unicode horizontal motion grows a grapheme window geometrically and keeps the pending cluster exact, including long combining sequences. The document owner's printable-ASCII range query now traverses partial rope ranges using absolute subtree bounds, so a valid ASCII subrange does not fall back to a full logical-line slice.

## Failure cases and recovery

- `DocumentSnapshot.slice` errors at a surrogate boundary are retried by shortening a bounded chunk; an unrelated read failure returns `document-read-failed`.
- A cursor with a sentinel end-of-line desired column falls back from the local Unicode horizontal calculation when tab-column inversion would be ambiguous, preserving existing exact semantics.
- The semantic regression includes a 1,024-mark combining cluster and passes in both directions without truncation.
