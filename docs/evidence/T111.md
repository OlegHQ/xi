## Observable result

The layout owner now retains hit geometry as numeric packed row/column values.
Display positions use a nested numeric index instead of a string key per cell;
`CellPoint` objects are created only when a public lookup returns a point. Frame
records share the immutable packed index for the published frame and cached
projection. Cache statistics expose retained frame count and materialized cell
cost so bounded retention can be checked.

The editor paint path now stores selection, trail and operator overlays as a
numeric bit mask keyed by packed row/column. It visits selection ranges directly
and resolves colors and attributes in the paint loop, removing per-cell mask and
style objects from the transient path. OpenTUI remains the owner of native cell
diff and terminal output; no second ANSI buffer was added.

## Failure cases and recovery

The focused layout fixtures preserve stale-frame rejection and evict old frame
indexes after the eight-frame limit. Resize disposal calls `ViewportLayout.dispose`
and the workbench lifecycle fixture passes cleanup. Stale presentation metadata
is rejected by the existing UI paint path, and the motion paint fixtures pass
after mask packing. No failure was found in the exercised functional cases.

Backpressure, blocked-output release, native buffer lifetime, cursor-only/row
damage behavior, and wide-glyph erase bytes were not measured by these commands.
