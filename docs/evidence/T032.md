## Observable result

`packages/vim/config/index.ts` provides immutable profile-scoped mappings with native reservations, bounded recursive expansion, deterministic prefix timeout and typed failures. The same module provides versioned option snapshots with value and global/buffer/window scope validation.

`packages/vim/operators/direct-changes.ts` provides pure, versioned plans for `s`, `S`, `C` and `r`. Character ranges use grapheme boundaries and UTF-16 document coordinates; `s`, `S` and `C` return Insert transitions and preserve the linewise indentation boundary, while `r` replaces a counted grapheme run and remains in Normal. No function mutates the document; the document owner commits the returned transaction.

## Performance and visual evidence

No rendered UI or keystroke latency budget applies to this pure operator/config planning slice. Direct scans are bounded to one logical line and use the document snapshot API; no whole-document or synchronous process/filesystem work is introduced.

## Failure cases and recovery

- Mapping recursion, exact-prefix timeout and unrelated suffix handling return typed results without changing the prior mapping state.
- Stale option versions, local/global scope collisions, invalid counts and malformed replacements reject the complete operation before a transaction.
- Direct changes reject unsafe UTF-16 boundaries and do not split surrogate pairs or grapheme clusters. Empty `s`/`C` lines produce an Insert transition with no edit.
