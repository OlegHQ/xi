## Observable result

`WorkbenchInputDispatcher` routes one canonical input event through the active `FocusGraph` target and the T074 `CommandRegistry`. Command key sequences are validated against the existing registry, resolve deterministically, and execute a handler once. Context and capability availability are captured for both dispatch and read models; unavailable commands return their declared reason.

`FocusGraph` owns stable target IDs, explicit directional edges, deterministic registration-order fallback, overlay focus, and restoration of a still-valid prior target. Opening an overlay clears pending key/operator-like prefixes. Escape cancels a pending prefix first and otherwise dismisses the overlay.

`CanonicalInputAdapter` is the production OpenTUI parser boundary for this slice. It guards split UTF-8 before OpenTUI's 20 ms Escape parser timeout, converts invalid partial scalars to U+FFFD text, and emits each parser event once. SGR and legacy X10 diagnostics retain raw protocol bytes; the legacy X10 conversion uses byte-string code units rather than UTF-8 re-encoding. `readPalette()` and `inspectKey()` expose immutable discovery read models backed by the same command registry generation and binding table.

## Failure cases and recovery

- `T035-FAIL-DISPOSED-01/02`: disposing the active target leaves a visible `focus-target-disposed` result and cannot route input to a removed handler.
- `T035-FAIL-PENDING-01`: a pending two-key sequence is cleared when opening an overlay; it cannot complete against the overlay.
- `T035-FAIL-ESC-01`: Escape cancels pending input or dismisses the top overlay, then restores the prior valid target.
- `T035-UTF8-01..07`: a valid split scalar survives a parser timeout as one text key; an invalid partial sequence emits U+FFFD and never creates an Alt command chord.
- `T035-RAW-01..03`: SGR, high-byte X10, and key diagnostics preserve exact raw hex bytes.
- Binding registration is atomic per call: unknown commands, malformed sequences, duplicate target/context sequences and missing targets leave the existing bindings unchanged.
