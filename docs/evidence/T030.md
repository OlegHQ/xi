## Observable result

`packages/vim/navigation/index.ts` owns versioned local, global and special marks, maps marks through `DocumentChangeMap` edits while preserving explicit affinity at deleted ranges, and reports missing cross-buffer targets without guessing. It also provides immutable jump and change lists with duplicate suppression, backward/forward traversal, branch truncation after a backward move, and a separate preview transaction whose cancellation leaves history identity unchanged. All coordinates remain branded UTF-16 offsets and document versions.

The public Vim barrel exports the navigation contracts and functions. No document, register or UI state is mutated by the navigation package.

## Performance and visual evidence

No rendered visual or latency budget applies to this pure navigation-state package. Mark mapping is proportional to retained marks and one change-map pass; jump/change traversal is constant time per move. No UI or document keystroke path is claimed here.

## Failure cases and recovery

Deleted mark ranges map to the chosen left affinity edge through the document change map; stale or wrong-document mapping returns a typed failure. A global mark whose document is unavailable is returned as `missing-document`, while local marks remain scoped to their source buffer. Consecutive duplicate jumps are suppressed, a new jump after backward traversal truncates the forward branch, and cancelling a preview preserves the original history object. Empty jump/change lists return typed boundaries.

## Limitations and next action

The pinned oracle harness exposes jump/change lists but not arbitrary user mark names, so local/global/special mark coordinates are validated by Xi invariants and the dedicated deletion/cross-buffer fixtures while the oracle validates the shared list outcomes. Automatic updates for every special mark produced by all future edit operators remain integration work owned by the command/history coordinators; this ticket provides the typed storage and mapping boundary.
