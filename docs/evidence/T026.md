## Observable result

The Xi-owned evaluator now integrates the regular Thompson NFA, bounded fallback extensions, positional and coordinate context, composing/NUL behavior, and snapshot-bound `iskeyword`, `isident`, `isfname` and `isprint` classes. The option context is immutable and version-bound; option grammar errors and stale contexts retain typed errors and pattern source spans. Option rules are charged to the evaluator work budget, so resumable slices and cancellation cannot hide a large class scan.

The integrated pinned matrix combines option-driven classes with reported spans/captures, branch intersection, Unicode POSIX classes, lookaround and backreferences. Existing family suites remain direct differential checks against pinned Neovim 0.12.4; Neovim is never started by production code. The only documented syntax boundary is `\\z(` syntax-highlighting-only grouping. T027 continues to own command-level search/substitute range/count/last-pattern/cursor/repeat integration.

VP-05's direct matrix contains 64 minimized cases: 62 spans match the pinned oracle, while two invalid Unicode option spellings are rejected by both Xi and Vim with source-aware errors. It covers all four option names, defaults, ordered inclusion/exclusion, ASCII and Latin-1 ranges, Unicode letters/digits/emoji, POSIX aliases, complements and no-digit classes. The pinned result records Neovim's observed distinction between ASCII-only `\\l`/`\\u`, Unicode POSIX lower/upper under engines 0/2, and the old-engine behavior.

## Performance and visual evidence

Visual evidence is not applicable to this pure in-process evaluator. Measurements are exploratory same-host Linux aarch64 runs with Bun 1.3.13 and no target latency threshold. Resume returns to the caller but does not itself schedule an event-loop turn. No editor command dispatch, terminal input, cursor/repeat integration or rendering latency is measured.

## Failure cases and recovery

Integrated fixtures cover zero-width repetition, magic-mode switches, ambiguous fallback workloads, output and work limits, cancellation, stale position/character-class contexts, missing visual/mark context, source-aware unsupported syntax, UTF-8 scalar-boundary rejection, composed/precomposed and detached marks, and NUL loaded through a real file buffer. A low-budget option-class session fails at the exact configured step with `{ start: 0, end: 2 }`; resume produces the same result and work count as an unsliced run. The immutable document version/text and caller cursor/repeat sentinel are unchanged across complete, budget, cancellation and stale-context paths.
