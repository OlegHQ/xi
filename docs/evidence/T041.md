## Observable result

`DirectoryDraft` creates an in-memory directory document from a base listing. Every row has an opaque generated or validated identity and an anchor offset independent of the escaped filename. Escaping is reversible for backslash, newline, tab, carriage return and control bytes. Rename, delete, yank, put and undo update only the draft and produce no platform calls. Pasted rows become explicit copy candidates with fresh IDs; imported identity-preserving pastes remain visible and are rejected during review when they duplicate an ID.

`compilePlan()` maps anchored rows to rename, copy and trash candidates, validates escaped names, rejects unknown identities, duplicate destinations and ambiguous rows, and reports the exact row/line/column while leaving the draft text intact. `openReview()` publishes a compact immutable review model. `DirectoryReviewRenderable` paints that model only, and `DirectoryReviewFocusLifecycle` opens a focus overlay whose cancellation restores the directory editor and leaves its draft unchanged.

## Failure cases and recovery

- `T041-FAIL-DUP-01` through `T041-FAIL-DUP-03`: identity-preserving paste produces a duplicate ID, review rejects it on the duplicated row, and draft text remains unchanged.
- `T041-ESCAPE-01` and `T041-ESCAPE-02`: newline, tab, carriage return and backslash filenames use reversible escaped rows; literal row breaks cannot be mistaken for a filename.
- `T041-FAIL-AMB-01`: rename to an existing destination reports a duplicate-destination error with row identity and retains the edited draft.
- `T041-INVALID-01` through `T041-INVALID-04`: malformed escapes report line and column while preserving the invalid text for correction.
- `T041-REVIEW-03` through `T041-REVIEW-07`: review cancellation disposes the overlay, restores the source editor focus, and preserves the draft text.
