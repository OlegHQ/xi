## Observable result

`WorkbenchRenderable` now paints split panes from an immutable layout read, creates separator hit regions, captures drag identity across other separators, enforces the configured pane minimum, and restores committed geometry on Escape, resize, suspend or disposal. Narrow layouts keep a single editor view while retaining the split tree. The launcher starts the OpenTUI mouse protocol without all-motion reporting and suspends/resumes the renderer around job-control stop/continue signals.

The current production control path covers sidebar section buttons, the active tab, status hit target and split separators. Explorer tree rows, picker/search/problem results, panel scrolling/scrollbars and context menus still have no production pointer targets. The status target is currently a no-op. These gaps keep the ticket open.

## Performance and visual evidence

Splitter movement is event-driven; there is no drag polling timer. OpenTUI runs button and pressed-motion mouse reporting (1000/1002/1006) without all-motion mode 1003. The terminal output and raw-mode checks were inspected from Linux kernel PTYs at 120x40 and 80x24. This does not qualify an actual xterm emulator, tmux, Screen, SSH, 256+ column terminal or physical display. The refreshed T116 startup diagnostic records p50 200.29 ms and p95 208.43 ms to first frame, still above its 150 ms target; see [the retained artifact](../../.artifacts/performance/T116/startup-revalidated-2026-09-16.json).

## Failure cases and recovery

- The first production splitter PTY found that separator cells were treated as editor blank space. Hit testing now checks captured splitters before editor/control fallback, and the nested E22 PTY passes.
- Minimum-size moves below 12 cells are rejected without changing the committed split ratio.
- Resize, Escape, suspend and disposal cancel pointer capture and restore the initial splitter geometry; SIGTERM and clean quit restore mouse, alternate-screen, cursor and PTY raw state.
- The first full `bun run check` found a type-only cycle between `read-model.ts` and `session/index.ts`. Shared layout read types now live on a structural public boundary; the final full check passes.
- One aggregate run hit the T086 five-second quit timeout; it passed standalone and in the next full interaction run after the harness allowance increased to ten seconds.
