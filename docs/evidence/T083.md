## Performance and visual evidence

Ex discovery is bounded by the command source segment and registry candidates and performs no document scan, filesystem IO or process launch. The production PTY fixture observes the real OpenTUI command-line rows. Full input latency and allocation qualification remains under T106/T115.

## Failure cases and recovery

Native-safe alias validation rejects native collisions and alias cycles without publishing a partial registry. Escaped separators remain path/pattern text. Dirty native close reports the explicit refusal and does not save implicitly. Escape routes through the owned Vim session and clears the command-line model.
